### D1：距离响应与真实 MC 条件预测

全部 18 模型，W48、真实间距10。

1. 单可见点：完整有效集合，其余为 MASK；查询固定为 [0,0]，可见点沿 x/y 轴相距 10,20,...,470，各取正负自旋。t=1-1/2304。MC 两点矩使用所选独立父场池，每 parent 128 个平移位置；零场对称化给出 p(query+|visible=b)=(1+bG)/2，保存 parent 级矩和链标识。
2. 分别把供给模型的坐标乘 0.9、1、1.1，查看距离响应。0.9/1.1 是错误坐标干预，不是另一真实采样布局；不能把它们作为正式“改进模型”。C 使用原有第一张样本的假坐标，明确这是固定假布局的诊断。
3. 使用原生成配对 MC 银行的 128 张真实窗口；t=0.2/0.5/0.8/0.95，共同 MASK，对三种坐标倍率测 CE/Brier。这里标签来自真实 MC，不给自由生成轨迹硬配另一张 MC 的标签。

单可见点是稀少信息条件，不能冒充一般遮挡分布。概率诊断使用 FP32/highest；正式生成保持原 BF16/high 规则。

### D2：闭合小 cavity 的精确联合分解

全部 18 模型，同一组 8 个 MC 外部构型，在 W16 上分别遮住中心2×2、3×3区域。固定完整外部，其中包含全部最近邻边界，所有穿过边界的 Ising 耦合都保留。

枚举16/512种内部状态。四种固定揭示分组：逐点行序、逐点逆序、每行并行、全部并行。

- exact sequential oracle：应严格还原条件联合分布，作为单测。
- exact marginal parallel oracle：用精确单点概率并行生成，量化丢失条件依赖的代价。
- learned sequential/parallel：在每个可能前缀上评价模型概率，精确计算诱导联合分布，不依赖有限生成频数估计 KL。
- 保存真值、oracle 和 learned 联合概率；验证固定分组的 KL = 条件单点 KL 累积 + 并行因子化 KL，浮点容差 1e-8。

时钟为 max(当前 cavity MASK 数 / 256,0.01)。这是与实际 MASK 量相容的诊断时钟，不是原 cos² 全图生成轨迹的精确重放；不能把这里的误差直接当成全图 sampler 误差。

固定分组的 KL 不是随机揭示顺序混合后的 KL。8 个边界例不是8次独立训练。这个最近邻精确 oracle 仅用于连续格点，不套到稀疏观测网格。

## 判别而非默认归因

1. 重算不一致：阻止依赖原G结果的解释，检查实现。
2. 真实条件/单可见距离响应也有异常：模型/位置表示贡献值得研究，不能只怪采样。
3. 更细步数改善：支持有限步采样是贡献因素，不证明它是唯一因素。
4. 坐标倍率让峰移动：支持坐标相关性，但该干预同时改变整个输入表示，不能只据此锁定某个RoPE频率。
5. 小 cavity 的oracle分解：精确区分该小条件问题的两类误差，不直接量化大窗口上的误差比例。
