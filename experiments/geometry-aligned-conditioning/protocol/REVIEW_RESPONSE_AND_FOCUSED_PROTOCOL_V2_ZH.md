## 2. 需要明确承认的原方案问题

原稿不是所有论述都错，但有三处存在执行风险。

**第一，停止规则过强。** 原稿把“数学 null 不通过”统一指向修复实现。这会把未硬编码的 spin-flip 对称性和 t 不变性失败也错误地看成代码 bug。它们可能恰恰是需要解释的学习失败。

**第二，cavity 的 reference 描述不闭合。** “把缺失边界点加入枚举”只有在它新增的外边界也处理正确时才成立。这不是措辞小问题；漏掉耦合会改变 Gibbs 分布。

**第三，默认诊断范围与研究目的不相称。** 全层 attention、时间捷径、频率手术、联合兼容性、采样大矩阵都有价值，却不应一起成为验证老师假说之前的强制门槛。

两个更准确的澄清也应保留：原稿已提示时间图样 OOD、cavity 可用条件 MC、零训练不等于零成本，所以评议不是发现这些概念完全缺席；但这些提醒没有充分落实成可执行规则，仍需实质修改。

## 3. 两道不同的检查：实现一致性与目标性质

### 3.1 Gate-I：结构/实现检查，失败只阻塞相关解释

适用于当前 A 后续坐标模型，而不是把所有网络一概套用：

- eval 模式下，联合重排 token、坐标、valid、query 和邻接，应保持对应位置的输出。
- PAD keys 被正确排除；增加 PAD 存储不改变有效 query 的物理输入。
- 仅通过相对 RoPE 进入的位置，在精确算术下共同平移不改变 attention；实现中需考虑大坐标三角函数误差、FP32/BF16 和 kernel 差异。
- identical-key 复制及精确 log-weight 补偿应满足代数身份；多层测试必须保证后续表示仍满足复制假设。

先小规模 FP32 reference，再比较部署精度。阈值按同一后端的重复/identity 基线制定，不把任意非零浮点差当成物理现象。失败时先定位输入变换、插桩或数值问题；只暂停依赖该项的结论，不要求整个研究无期限停摆。

### 3.2 Gate-P：物理/后验诊断，失败是结果

包括 spin-flip equivariance、full MASK 单点 1/2、固定信息下 t 不变、blanket 精确条件律。这些是目标性质，但当前模型一般没有全部硬编码。

正确流程是：测量偏差 → 判断在哪种输入分布下出现 → 决定与主问题是否有关。不是“通过后才允许研究”。例如极端遮蔽的 t 敏感性很大、正常条件任务仍准确，可以保留为边界现象，不能据此强行把主线改成 time-free。

**一个细分：**当前纯 Q/K 位置通道、所有 token 输入相同、无额外位置 value 通道时，full MASK 下不同位置的输出相同可由结构推导；但这个共同概率是否等于 1/2，仍是目标/学习性质。连同一个 full-MASK 测试也包含两个不同层级。

## 4. 时间诊断：采纳三个 estimand，再把它们定义到可执行

### 4.1 stress 数值复核与边界

在 N=4096、每点可见概率 0.05 的独立模型下，本次计算：

\[
P(K_{vis}=4)=5.1223005\times10^{-84}.
\]

恰好是指定四个位置可见的概率约为 \(4.37394\times10^{-97}\)。这确认评议的数量级。若某 query 被强制 MASK，需要相应改计数分布；这里是对评议所列 iid 模型的核验，不把它当所有训练/采样机制的概率。

它说明原 stress 图样在 t=0.95 下极不典型；**不推翻后验不变恒等式，也不估计实际生成中这类图样的占比**。在更接近 1 的 t 下，“四个可见”可以合理得多。

### 4.2 三个不混合的量

1. \(S_{stress}\)：预定极端图样固定，扫描宽 t 区间的概率/真值 KL 变化。测反事实鲁棒性。
2. \(S_{natural}\)：从真实 forward corruption 或实际 sampling trace 取得图样，在与其生成机制相容的时间邻域内测敏感性。两种图样来源分开报告。
3. \(\Delta R_{repair}\)：冻结一项时间处理修正后，在合法 heldout 条件任务和生成任务上风险是否改善。只有这一项能支持修正的实用收益。

“natural 时间邻域”不能继续随意定义为四个固定数。若时间先验为 π(t)，随机可遮蔽位置有 n 个、实际 MASK 有 m 个，则

\[
\pi(t\mid M)\propto \pi(t)t^m(1-t)^{n-m}.
\]

在均匀先验部分相当于截断的 Beta(m+1,n−m+1)。强制 MASK 的 query 不应算进 n；full-MASK 概率质量、t 截断及离散采样网格按实际机制处理。这只是诊断支持的定义，不是把现有 sampler 的时钟随意替换成“更好看的 t”。

用这一支持的预定分位点比较同一输入，可避免把明显不相容的 t 扫描冒充自然效应。但随 N 增大该时间范围往往收窄，敏感性更小也不能单独证明模型更稳健；同时报告扰动幅度。

### 4.3 16 模式的 logit 分解，比仅报极差更强

评议建议 \(\ell(n)=a\sum_j n_j+b+r(n)\)。这个方向正确，但 r 同时可能包含对邻居和的非线性与方向不对称，不能统称“排列处理变化”。

对全部 16 个模式，采用均匀内积的精确 Walsh 展开：

\[
\ell(n)=\sum_{A\subseteq\{1,2,3,4\}}c_A\prod_{j\in A}n_j,
\quad c_A=\frac1{16}\sum_n\ell(n)\prod_{j\in A}n_j.
\]

精确最近邻条件 logit 对应：c_∅=0，四个单点 c_{j}=2βJ，其余系数为 0。

- 截距：spin 偏置的一个成分。
- 单点系数平均：总体置信斜率。
- 单点系数之间的差：方向不对称。
- 非零偶数阶系数：违反 logit 的 spin-flip 奇性。
- 三阶系数：即使保持 spin-flip，也可能违反精确 Markov 条件律。

使用原始 logit 差，避免概率接近 0/1 后截断制造残差。固定模型穷举无需对 16 行 bootstrap。这个分解是新增计划，当前没有重新运行模型来获得 16 模式表。

## 5. 双可见自旋：应当前移，但要补四项限制

### 5.1 公式正确，本次独立验证

在零外场、spin-flip 对称、没有其他固定非对称观测的母场中，三个不同自旋满足

\[
p(a,b,c)=\tfrac18(1+abG_{ij}+acG_{ik}+bcG_{jk}),
\]

所以

\[
p(s_i=+1\mid s_j=b,s_k=c)
=\tfrac12\left[1+\frac{bG_{ij}+cG_{ik}}{1+bcG_{jk}}\right].
\]

本次在可枚举的 3×3 周期零外场系统上测试四组三点、每组四种符号，最大误差约 1.11×10⁻¹⁶。此为恒等式核验，不是现有模型能力结果。

它能区分“两条证据的单独相关性”与“证据之间的冗余”，比单可见点更接近老师的问题。这项建议应当进入默认路线，而非作为遥远扩展。

### 5.2 MC reference 必须保持联合一致性

不要用互不相关的三个小 MC 估计分别拼 Gij、Gik、Gjk，再忽略误差构造条件概率。有限样本可能违反联合概率非负约束，罕见条件事件尤其敏感。

优先从**同一批母场/平移位置的三元组**保存八种状态计数；在明确零外场对称目标下，可将计数与全局翻转后的计数合并，得到显式标注的 Z2-symmetrized reference。由同一 reference 得到三个关联和条件概率，并按链/时间块共同重采样。

这个参考的对称化不是强制每张图 m=0，也不是对模型输出偷偷做后处理。

事件概率为 \(p(s_j=b,s_k=c)=(1+bcG_{jk})/4\)。分母很小时，报告事件频率/有效精度；reference 不足则标记“不确定”，不把 noisy ratio 的显著变化包装成模型错误。均衡四种符号的 stress risk 与按真实事件概率加权的部署 risk 分开。

### 5.3 不是所有同号/异号组合都有相同判别力

若 Gij=Gik、b=−c，分子严格为零，查询概率为 1/2，与 Gjk 无关。因此**等距、异号的对称情形应作为信息融合的 null control，不能用它检测是否读懂证据—证据距离**。

一个更清楚的设计：query 在 (0,0)，j 在 (r,0)，比较 k=(0,r) 与 k=(−r,0)。在方形母场的 D4 对称目标下，query 到证据的两个关联相同；证据间位移分别是对角与轴向更远距离。

- 两证据同号：考查冗余修正。
- 两证据异号且对称：应为 1/2 的 null。
- query 到两证据不等距、且证据异号：再考查冲突消解。

实际 reference 使用位移向量而不是把短距离格点全部视为连续旋转对称。改变合法物理布局时重新从相应位置取 MC；只改变模型收到的坐标是错误输入干预，不能用它替代另一合法布局的准确率。

### 5.4 通过这个测试仍不是“学会完整几何推理”

零外场的三点联合在此处完全由二点矩决定。一个学会 G(位移) 并套用融合公式的模型也可以通过，这已经有价值，但不是高阶多点分布正确的证明。

因此双可见测试作为主几何证据之一，配合普通随机 MASK 任务；不替代完整生成。三可见点会涉及四点矩，可留作以后区分更高阶能力的测试，**本轮不因想到它就扩张默认预算**。

## 6. cavity、联合 KL 与自由轨迹的正确真值

### 6.1 未知集合扩展后，边界必须闭合

对未知集合 U、完整已知边界 ∂U=y：

\[
p_U(x\mid y)\propto\exp\left\{\beta J\left[
\sum_{\langle i,j\rangle\subset U}x_ix_j+
\sum_{i\in U,j\in\partial U,\langle i,j\rangle}x_i y_j\right]\right\}.
\]

边界内部的常数能量不影响归一化，但所有跨 U—∂U 的键必须保留。

对 2×2 内域 C，隐藏一个原边界点 u 后用 U=C∪{u}，并固定新的完整外边界。选 u 与 C 的一条边相邻，则本次示例有 5 个未知点、9 个边界点，枚举 32 状态。

在本次数学示例中，仅翻转更外侧一个可见自旋，原 cavity 内一个 query 的精确 + 概率由约 0.95659 改为 0.93626。这证明该闭合构造确实可以让“对原区域较远的证据”产生合法影响。**数值只验证 fixture，不代表模型已经学到这个影响。**

这更适合称“信息传播的反转测试”，不是一步证明任意长程推断：新增远端点只通过一个或少数潜变量传播。

### 6.2 采纳 KL 分解，不增加一个虚构的第三项

对固定、与自旋值无关的揭示分组 π=(B₁,…,B_K)，每组内部独立采样：

\[
Q_{\theta,\pi}(x)=\prod_k\prod_{i\in B_k}q_{\theta,i}(x_i\mid x_{V_k},t_k).
\]

若概率归一化且目标支持包含于 Q 的支持，则 KL 链式规则给出

\[
D_{KL}(p_*\Vert Q_{\theta,\pi})=
\sum_k E_{p_*(X_{V_k})}\left[
\operatorname{TC}_*(B_k\mid X_{V_k})+
\sum_{i\in B_k}D_{KL}(p_*(X_i\mid X_{V_k})\Vert q_{\theta,i})\right].
\]

这是 forward KL，期望沿 **p 的前缀分布**，不是随意把自由生成轨迹均值塞进右边。插入真实单点边缘乘积，第一项是 joint 相对乘积分布的 KL，第二项经边缘化得到各单点 KL，因而等式成立。

顺序不兼容不是独立、可加的第三项；固定顺序仍定义正常归一化 Q。不同顺序可以产生不同 Q，兼容性用顺序间 TV/JS 或闭环残差另测。

### 6.3 本次枚举核查：公式通过，但不包装成实验成绩

同一 2×2 cavity、固定边界，构造一个人为带误差的条件预测器，结果如下（nat）：

| 数学测试 | 联合 forward KL | 条件 total correlation | 单点 KL 项 |
|---|---:|---:|---:|
| exact oracle、串行 | 约 0 | 约 0 | 0 |
| exact oracle、并行两点分组 | 0.106476 | 0.106476 | 0 |
| 人为近似 predictor、串行 | 0.032668 | 约 0 | 0.032668 |
| 人为近似 predictor、并行两点分组 | 0.138426 | 0.106476 | 0.031950 |

等式最大数值残差约 5.56×10⁻¹⁶。浮点的 −10⁻¹⁶ 量级 TC 为舍入误差，不是负的物理代价。“人为近似 predictor”不是本项目训练的模型。

### 6.4 随机顺序与 mixture 需要分表

如果顺序以固定、与 x 无关的 ν(π) 抽取，最终分布为 \(Q_{mix}=\sum_\pi\nu(\pi)Q_\pi\)，则

\[
D_{KL}(p\Vert Q_{mix})\le E_\nu D_{KL}(p\Vert Q_\pi).
\]

右侧可按分组分解平均，但通常不等于左侧。本次 fixture 的两串行顺序平均 KL 约 0.03538，mixture KL 约 0.03192，已经是一个严格不等例。

当前 value-blind reveal 可条件于预先抽取的时间/分组来做这个分析；confidence 或自适应顺序则涉及不同的顺序选择机制，不能直接当 ν 与 x 独立。未验证的版本不列为默认 sampler。

### 6.5 两种限制仍然不能忘

**小 cavity 准确，不保证大尺度生成准确。** 局部一致性和很小的每-site 条件误差，仍可能在临界、大体积与自由生成中产生明显宏观偏差；还需要有限但真实的生成桥梁。

**oracle 有偏，不自动阻塞几何训练。** 并行近似偏差预期存在。是否构成瓶颈，应看预定任务上超过容差/改变方法排序的程度；如果下一步只声称条件几何推断，其采样问题可以并行保留，不必先修到零。

### 6.6 teacher-forced 与 free-running 的 reference 契约

- MC teacher-forced：使用该 MC 样本自身的可见值与 query 标签；平均 CE 是相应 forward-mask 任务的估计。
- 自由生成条件：可见值为 \(\tilde x_V\)，真值必须是 \(p_*(X_Q\mid X_V=\tilde x_V)\)。需 exact cavity 或条件 MC。
- 同几何/同 MASK 换一张 MC 图，只配对了缺失位置，没有配对条件状态。不得用新图的 query 标签给旧生成可见值算“真值 CE”。
- 没有 matching oracle 时，只报兼容性/对称性/概率位移，不称真实条件风险。
- 比较状态难度不同时，优先用相对各自 oracle 的 KL/excess risk；原始 CE 含有 Bayes entropy，不能直接当失真程度。

## 7. 聚焦版 Plan S：一轮 S0–S3，不把所有好想法都执行

### 7.1 固定 cohort 与成本口径

默认最多三个现有 checkpoint：

- D：Dense-T3+，用于纯 dense 基准与原局部诊断。
- L：LG-T3，用于检验原诊断—生成关系。
- G：Gap-Matched，仅用于已有几何正面信号的更严格检查。

先核对各自 best/last、EMA、step、hash；如果归档 best 与原评价 last 不同，则单独建新的 cohort，不声称精确复现旧结果。G 和 D/L 训练数据、架构不同，不能把它们的横向差值当纯几何训练因果效应；这个阶段主要做各模型内部的 paired probes。

“样本级前向等价值”指一个输入构型在一个时刻的一次 denoiser 计算；批处理 B 个构型的一次调用计 B 份。这不是 API/kernel 调用次数，也不是统一 FLOPs。另保存 batch NFE、有效 N、attention 层数、wall time、显存。

| 阶段 | 默认范围与硬上限 | 必须回答的问题 | 不默认做 |
|---|---|---|---|
| S0 证据/实现/16 模式 | D/L；blanket W16 与 W64；不超过 1,024 样本级前向，N≤4,096 | 哪些是真正实现问题，哪些是物理目标偏差？ | 多模型全层 attention 记录 |
| S1 直接几何能力 | D/L/G；12 个预定几何，单/双可见点、合法布局与摘要保持干预；不超过 1,024 前向，N≤1,024 | 是否按真实相对布局正确融合证据，而不只是平均尺度？ | 新的 RoPE 频段扫描和更大 token context |
| S2 精确小 joint | D/L；2×2 为主；有限闭合五自旋反转；不超过 2,600 前向，N≤256 | posterior 与并行分解各自贡献什么？顺序是否一致？ | 3×3 全部部分状态、所有随机顺序 |
| S3 最小生成桥梁 | D/L；先复用归档 W64，再必要时 W32/W64 每模型每尺寸最多 32 图、固定 K=256 | 几何/条件诊断与真实生成是否方向相容？ | 默认多 K、多个温度、对称化和 MC 校正 |

这些是建议上限，不是本轮已获执行授权的任务。不因出现新现象而自动加倍样本或添加第四个模型。先用每种代表 batch 的计时折算 wall-time 上限，开始收费运行前确定预算；不能靠前向数声称已经知道会运行几小时。

### 7.2 S0：16 模式与自然输入，分清失败层级

1. 用小输入通过 Gate-I；默认 FP32 reference，部署精度单独比较。
2. 构造全部 16 个四邻居模式，固定方向次序，测试 Small/PAD/Large-MASK。主 stress t={0.2,0.5,0.8,0.95}；复用旧记录可节省重复计算，但新 cohort 需明确区分。
3. 概率、精确 KL、原始 logit 与 Walsh 系数同时保存；区分常数偏置、斜率、各向异性和高阶残差。
4. 从少量真实 forward-mask 输入取得自然图样，测相容时间范围的敏感性；不把原四点 blanket 当自然样本。

主要输出是完整模式表和“structural / physical / numerical”问题分类，不是另一个“下降百分比”。Gate-P 不通过可以继续 S1/S2。

### 7.3 S1：把老师的问题放回默认核心

12 个几何在前向前固定，覆盖：

- 单可见点的近/中/远位移响应，保留 x/y 方向。
- 双可见同号、冲突、冗余关系；至少包含第 5.3 节的对称 null 和非零效应配对。
- 摘要保持干预：相同轴向 gap 多重集、总跨度、有效 N，改变布局；明确哪种局部摘要没有被控制，不声称排除所有 shortcut。

12 个几何中保留一组合法无信息扩充对照：保持同一坐标范围、核心 query 与可见点，增加范围内其他真实位置的 MASK 点。它不引入新的坐标范围，可用作计数分支的廉价触发信号；但仍改变位置集合，单靠它不能将全部效应归因于 softmax 分母。

参照使用同一批物理三元组计数和共同不确定性。每个正确物理布局的准确率，与“固定 spins 给错误坐标”的依赖性结果分列。单/双可见点本身是受控稀疏观测任务，不等于典型随机 MASK 性能；保留已有/小批普通 MASK 风险作为外部检查。

最多两个预定 reported-t 条件：机制相容条件为主、一个明示 stress 条件为辅。不要对测试逐个选择最有利的 t。评价 geometry-specific true risk，不只问输出是否变化。

### 7.4 S2：81 个部分状态可缓存，不需要大规模 rollout

默认选 8 个事先定义的 2×2 cavity 边界图样，包含同向、相反、条纹和局部扰动；不是看到模型表现后再选。

每个四点未知域的部分状态有 3⁴=81 种，其中 16 种已全可见，无查询需求，可省略前向。一次模型前向同时保存全部未知点预测，串行两顺序和预定并行分组从同一缓存构造；不要为每条采样路径重复调用网络。

默认在 W16 的有效网格中嵌入 cavity：真实边界可见，其他远端点保留 MASK；模型只被要求生成 cavity，其他点不参与揭示。物理边界屏蔽保证 interior reference 不受这些未知外部影响。reported-t 用预定的全输入实际 MASK 比例函数，固定于部分状态；不能拿“cavity 剩余比例”冒充整个输入的 MASK 比例。这个任务是条件生成，不是 full-W16 采样。

四格表：exact oracle / learned posterior × serial / parallel。沿 p-prefix 精确求 KL 分解，另报两个串行顺序的 TV/JS。五自旋扩展只用两份配对边界作反转，至多 3⁵=243 部分状态/边界；完整闭合边界使用独立 reference，不能套零外场双可见公式。

2 模型×8×81 + 2 模型×2×243 = 2,268 个前向的保守上限，低于 2,600 配额；缓存后改变几种固定分组不额外增加模型前向。多个 t 每个都会增加缓存维度，所以默认不做大 t sweep。

**重要新增限制：**这 8 个边界案例不是临界系综的独立统计样本，不能 bootstrap 边界案例假装得到总体生成置信区间。它们首先是预定挑战集；若需要部署加权风险，另估 MC 边界权重及其不确定性。

### 7.5 S3：固定一个 sampler，先让现有数据说话

先对原 W64 样本及配置建立与 checkpoint 的映射，复用可以确认来源的产物。若需要新桥接，D/L 两模型、W32/W64、每组合最多 32 图、K=256、temperature=1、无后处理。

如果全部重跑，最大样本级前向为

\[
2\times2\times32\times256=32,768,
\]

而旧矩阵例子是 245,760，前者为后者的 1/7.5。**这不是实际运行时间缩短 7.5 倍的保证**：N、层数和 batch 利用率都影响成本。能够复用 W64 时，仅新跑 W32 更少。

32 图只检查明显的下游脱节、实现和趋势，不能给出小幅增益显著性或最终物理结论。预先固定输出：raw G、P(m)、每键能量、MC-vs-MC 小样本波动。若误差条太宽，结果写“不确定”，不根据哪种结果更漂亮决定追加多少图。

## 8. 触发分支、停止条件与不无止境诊断

### 8.1 默认只允许一个追加机制分支

| 分支 | 必须先有的信号 | 追加范围 | 怎样避免自证 |
|---|---|---|---|
| multiplicity/attention 竞争 | 相同坐标范围内，添加真实不同位置的无观测 MASK 仍可复现漂移；尚不认定主因 | 1 模型、≤32 anchor、≤3 count；先单层后必要时全层 | 复制＋补偿成功只是单测；需在合法新位置上恢复真值风险并对比普通温度/校准控制 |
| time 处理 | 自然输入的相容 t 范围内有实质误差变化，而非只有极端 stress | 1 个预定处理、仅 validation 决定规则；再冻结到另一宽度 | 不在每张测试图挑 t；time-free 需要新训练，不能称零成本修复 |
| sampler 分组 | S2 的并行 TC/误差足以阻止预定精度或改变比较 | 1 个额外分组/步数协议；先缓存 cavity 再少量生成 | 同 NFE/成本副比较；不以“偏差非零”作为主线停摆理由 |

追加诊断的前向量最多为 S0–S2 合计上限的 20%（向下取整 929 份），且 N 不高于触发的原实验。追加生成不包含在这个廉价配额里，需另报预算。没有触发信号，不做 frequency surgery、full activation dump 或多 sampler 搜索。

### 8.2 哪些情况停止，哪些只降低 claim？

- Gate-I 的关键错误：暂停依赖该输入/接口的实验解释，修复后重测；其他独立数学/文档工作可继续。
- 物理性质没学好：不停止整个项目，记录范围并做对应测试。
- oracle parallel bias 非零：不自动停止；只有超过预定容差且是当前 generation claim 的瓶颈才改采样。
- reference 不可识别、checkpoint 不可对应或几何任务没有可测信息：可作 NO-GO，说明需要什么补充资源，不强制开始训练。
- 到达 S 的上限：作出 A/B/C 决策——选一个 teacher 对应的训练比较；或先修关键接口；或明确本轮无足够证据。不能继续自动添新 probe。

因此我只部分接受“有限 S 后必须训练”的字面要求。应当必须**决策**，不是必须花掉 GPU 预算。研究纪律既要防止无限分析，也要防止为了推进而训练没有可识别结论的模型。

## 9. Plan M 的衔接：保持老师主线，补齐训练语义

### 9.1 默认候选主比较

如果 S 未发现致命实现/reference 问题，优先考虑同一纯 dense 底座的 M-G：**同一真实 sparse-window 数据流，matched vs unit 正常部署**；若要排除位置正则化，则加同数据、独立错配几何控制。

这个比较测的是指定容量、预算、优化规则下“几何对齐训练策略”的效用，不是纯信息论量。单/双可见点的 Bayes reference 为它提供解释，但不能把一般 heldout CE 差直接叫作互信息。

如果老师当下更需要多 W 的独立效应，选择 M-W；若要同时声称 W 与真实 spacing 的主效应/交互，才需要 M-F。机制诊断不能代替这些训练干预。反过来，某个 sampler 有已知近似误差，也不应阻止单独验证条件学习假说。

原方案的 dense 架构、优化起点可以保留，但不会因为 stress t 敏感就立即去掉 time conditioning。若实施任何修正，主要比较各组统一使用，不让 treatment 独享修复。

### 9.2 50% 到底是什么？V2 明确定义为有效 token

训练总预算 T_valid；continuous 与 RandomGap 各分配 T_valid/2，不按 batch 或窗口数对半。

默认各类内部的 W∈{16,24,32,48} 也按有效 token 配额分配：每个 (data class,W) 单元分配总预算的 1/8。同一个优化更新可用微批累积组合 token 配额；末尾不足配额的处理预先固定。

loss 聚合必须与该定义一致。若沿用 1/t 加权 masked CE，则先累加各 microbatch 的加权损失和，再除以该次更新的总有效 token，不能把不同 token 数的 microbatch mean 等权相加。

日志同时保存：window 数、有效 token、实际 masked targets、Σmask/t 权重、每 width/gap 暴露、完整/部分真实最近邻可见次数。50% 有效 token 在期望上约束了该目标的梯度分配，但不保证每次 realized mask、所有可见邻域类型都有 50% 暴露，因此后者仍需实测。

### 9.3 RNG 配对必须落到 ID/hash，不能只写同 seed

建议独立流：初始化、父场/构型抽取、origin、width/真实几何、独立错误坐标、数据增强、t、MASK、验证、采样。可用明确 domain tags 的 SeedSequence 派生，或用 (experiment_seed,sample_id,stream_tag) 的无状态计数方式。

matched/unit/独立几何三组的 parent/origin、真实 spins、augmentation、t、MASK 必须可逐 ID 核对。独立错误坐标只消耗自己的 RNG，不得推动父场/MASK 流。首次 smoke 对前 100 个 sample ID 的 clean/mask hashes 作断言；断点恢复保存每流状态或计数器。

当前 `train_stage2.py` 已把 NumPy training_rng 与 Torch device_generator 分开，不能说原代码完全没有分流；但 NumPy 流仍服务多项数据操作，也不能仅凭同 seed 就保证未来增加控制分支后继续配对。V2 要求的是显式合同和验证，不是无证据指控现有 matched/unit 一定失配。

### 9.4 防止为了证明先验而变更目标

最终训练判断仍回答老师的问题：真实相对几何是否帮助未训练布局/距离的条件推断，以及这种收益能否在预定生成任务中保留。

更广泛的随机场一致性、世界模型或全新采样器，可作为另一路研究结论，但应和老师重新确认，不从一个诊断阳性自动替换主项目。

## 10. 统计修订：这些意见成立，但不应被误读

### 10.1 三个 seed 的符号检验例子正确，结论不是“必须六个”

在三个独立配对差值、零假设下正负等可能且无 ties 的双侧精确符号检验中，即使同号，最小 p=2/2³=0.25。

这提醒我们：很多 test windows 不会创造训练层面的独立重复。但它不意味着任何基于三个 seed 的估计都无价值，或参数模型永远不能给较小 p；后者要依赖额外分布假设。也不能反推出凑够某个固定 seed 数就算严格确认。

在运行前写明目标：估计均值/异质性、非劣/等价、还是方向检验。受限预算时先报每 seed 的配对效应与 reference 不确定性，清楚标记为初步复现。

### 10.2 Plan S 不能估计不存在的训练间方差

接受这一纠正。Plan S 可以估计固定模型的测试/reference 波动、干预效应与耗时，不能从不同架构之间的差异推算某一训练策略的 seed 方差。

正式样本量可采用：可信历史同协议重复；预设保守方差区间；或预先约定的初始重复与方差再估计。不能看效果好就停止、效果不好就加 seeds。若用顺序检验，提前规定停止与错误率控制；若只是描述性估计，明确不包装成已达确认显著性。

### 10.3 机制不是一张相关散点图

“指标较好”和“生成较好”同时出现，可能都由总体模型质量驱动。更强的证据链是：

1. development 上提出能给出方向预测的机制；
2. 冻结一个针对该机制的干预；
3. 在另一宽度/几何/独立训练重复上，同时降低机制缺陷与正确 reference 风险；
4. 对照同成本但非针对性的校准/温度变化；
5. 报告诊断改善却生成未改善的情况。

干预降低风险但没有改变目标机制指标，也应反过来质疑指标的解释力。全部阳性都不能取代失败案例。

### 10.4 继续保留原层级统计方案，但加上 exact-case 特例

training seed 与 MC chain 交叉；链内 parent 可能时间相关；crop/MASK 与 sampling seed 不替代训练重复。按正确单位配对与重采样，少链时不伪造窄 CI。

16 blanket 模式和固定边界 cavity 是完整枚举或有限挑战集，不能按其中的输入状态做普通 bootstrap 来制造“自然分布置信区间”。它们的数值误差、边界权重不确定性、训练间不确定性要分别处理。

## 12. 最终评价与给团队的简短结论

这份意见最有价值的地方是把方案从“有深度的探索库”推进到“有边界的执行协议”。其技术修正大多成立；双可见公式与 KL 分解也经独立枚举核验。

我保留三点不同意见/进一步限制：

1. 完成有限 S 后应必须决策，不应在 reference 或实现不可靠时强制训练。
2. 双可见测试强于单点，但仍只涉及零场三点分布的二点矩结构；有些对称冲突案例应作为 null，不是 positive geometry test。
3. 三 seed 的 p 值例子说明信息不足，不是一个适用于所有推断目标的固定 seed 门槛；层级模型也不能弥补真正独立重复的缺失。
