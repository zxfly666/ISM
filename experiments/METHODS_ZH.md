# 实验方法与指标入门

本项目用临界二维 Ising 系统研究条件推断与尺度外推。读实验前先分清三件事：模型输入包含哪些信息、测试真值从哪里来、指标是在评价局部预测还是整张生成图。

## 模型在做什么

Ising 场中的每个格点取自旋 −1 或 +1。条件模型看到部分自旋，其他位置被标为 MASK，并接收坐标和时间输入 t；它预测被遮住位置取 +1 的概率。它不是直接拟合一条关联函数，也不是预测时间演化的视频模型。

后期主要实验使用约 198 万参数的 dense Transformer：128 维、4 个头、7 个 block、二维 RoPE。不同实验对训练任务、K/V 来源、尺度嵌入和精度有各自规定，不能把它们称为完全相同的模型。早期 L64 基线则是约 1270 万参数的轴向 attention 模型，不能把其结构、训练结果或权重谱系套到后期实验。

dense attention 指有效输入位置之间可以进行全连接注意力交互；Q/K决定关注谁，V提供被聚合的内容。RoPE是把坐标编码进Q/K的旋转位置编码。本项目不仅问网络是否收到了坐标，还问这些坐标是否对应真实取样位置、是否被模型有效利用。

Ising是本项目的物理试验台。相邻自旋的相互作用决定概率分布；临界设置使局部规律与跨距离统计都值得检验。MC是Monte Carlo参考采样，用来估计模型应匹配的物理统计，不是另一个神经网络。参考样本也有有限样本误差和链内相关，不能把MC曲线当作没有不确定性的真值。

## 一轮实验从训练到判断如何进行

先固定数据划分、对照组、预算、主权重和判据；再按计划训练；用不参与训练的数据评价；最后比较配对差与原定门槛。不同实验的数据和门槛不同，但不能在看见测试结果后挑选有利seed或改换主指标。

raw是某一步的原始网络权重；EMA是训练过程中权重的指数移动平均，能平滑更新，但不保证每项任务都更好。主权重依各轮方案固定：例如G/I使用12k EMA，N/W使用8k raw。checkpoint不仅可能含模型，还可能含优化器、随机数状态和数据计数；只载入EMA做预测不等于完整恢复训练。

下面的多数条件报告评价的是一个隐藏查询点或一组查询点，而不是一次直接给出所有隐藏点的正确联合概率。先看清测试任务，才能解释损失下降的含义。

## 尺寸与物理距离不是同一个变量

| 名称 | 含义 | 容易混淆之处 |
|---|---|---|
| W | 后期输入网格的有效边长，例如 W48 通常有 48×48 个有效位置 | 不等于父场边长，也不自动等于物理跨度 |
| L | 完整物理晶格或 MC 父场的边长，具体依实验定义 | L1024 父场可以提供许多小窗口，但这些窗口不是独立父场 |
| spacing 或 gap | 相邻采样点的真实物理距离 | token 索引相邻，不代表物理格点相邻 |
| span | 一条坐标轴的末点与起点之差 | 相同跨度仍能有不同内部间距排列 |
| K | 可见自旋数 | 低 K 表示观测少 |
| M | 被遮住的有效位置数 | 低 M 表示剩余未知点少，与低 K 是相反区间 |
| valid MASK | 物理输入范围内的未知位置 | 在原 dense 模型中可以参加 attention |
| invalid PAD | 为统一张量形状而填充的无效位置 | 应被排除；增加 PAD 与增加 valid MASK 是不同干预 |

例如，同样使用四个 token，坐标可以是 [0,1,2,3] 或 [0,1,4,7]。第二种布局不仅跨度不同，内部间距也不同。仅把第一种自旋数据的坐标标签改成第二种，不等于真的从第二种物理布局采样。

G 的间距干预同步改变物理取样与输入坐标；I 则保持物理输入不变，只改变向模型提供的坐标信息。前者问训练覆盖，后者问正确坐标的增量作用。

## 时间输入不是物理时间

原 masked diffusion 中，t 控制随机遮盖概率，也作为模型输入。有限样本中的实际遮盖比例不必恰好等于 t。某些诊断用实际 K 和有效 token 数定义 native clock；N/W 固定 t=.75，避免容器扩大时连时间输入一起改变。

因此，“固定 clock 多尺寸有效”不能回答“固定 clock 比 native clock 更好”。后一个比较属于未正式启动的 size×clock 方案。

## 条件预测与整体生成

条件评价把真实样本中的观测自旋交给模型，检查隐藏点的概率。整体生成从未知场开始，多次调用模型并采样、提交自旋；后续输入含有模型自己产生的值。

两者之间至少有三种差别：真实条件与生成条件的分布不同，多位置并行预测可能忽略联合依赖，先前提交的错误可能传播。因此条件 CE 或局部 KL 改善，不能单独保证全图分布正确。生成还要与同尺寸 MC 比较关联函数、能量、磁化及其他预定物理指标。

## 四类指标怎样读

### 条件交叉熵 CE

令 p 是模型预测 +1 的概率，y 为实际标签 0 或 1，单点损失为 −y log p −(1−y) log(1−p)。这里使用自然对数，单位通常是 nats/query。相同任务、相同标签和相同加权下越低越好。

粗尺度与细尺度目标的熵可能不同，不能直接用两者 CE 的大小判断哪一种物理任务“更正确”。后期报告中的条件 CE 也不是整张图的联合负对数似然。

### 精确局部 KL

只有知道局部真实概率 q 时，才能直接计算 Bernoulli KL：q log(q/p)+(1−q)log((1−q)/(1−p))。它为零表示该条件概率预测准确。

Basic 的小系统和 N/W 的有完整边界的局部腔体可用枚举求真值。N/W 的 G8 任务隐藏 2×2 腔体、观察八个边界自旋，枚举 16 种隐藏状态。给定完整边界，扩大外侧 MASK 容器不会改变这一局部真值；这使它适合测试容器鲁棒性。

早期某些 sequential KL 来自有限 MC 估计的局部条件表，不应称为全图精确 KL。RG 粗尺度目标只报告经验 CE，不套用细格点最近邻公式。

### 生成关联误差 NRMSE

比较生成样本与 MC 参考在指定距离区间的关联函数，按各轮冻结定义归一化。W96 的 G25–48 指相应生成评价的距离 25–48 区间，不是“25到48个可见点”。不同实验的距离区间与归一化可能不同，数值不可直接跨轮排名。

低关联误差只说明指定统计更接近参考。能量、磁化或短程关联仍可能变差，不能把一条好看的长程曲线当作分布已正确。

### 一致性与准确性

上下文一致性检查删去或增加部分上下文后输出是否一致；顺序 TV 检查不同预测顺序导出的局部联合表有多大差异。稳定或自洽的模型仍可能稳定地给出错误答案。F、固定背景诊断及 J 都说明必须同时评价准确性。

## 如何读误差条和通过判据

多数报告定义差值为“新方法减对照”，对损失而言负值有利。但 signed magnetization 和 energy bias 的目标是零，不能一概说越负越好。

| 判断 | 问题 | 示例 |
|---|---|---|
| 点估计有利 | 当前样本的平均差是否为负 | 不是已经排除随机误差 |
| 方向通过 | 预定区间的上界是否小于 0 | I 的 F−S 在指定主任务上有方向证据 |
| 实质门通过 | 区间上界是否低于预定负阈值 | I 的 F−S 点估计低于 −.002，但上界仍高于 −.002，因此实质门未过 |
| 绝对能力通过 | 模型误差是否足够小，而不仅仅比对照好 | N/W 平均改善大，W 的最坏误差门仍为 0/6 |
| 完整实验门通过 | 所有预定必要条件是否同时满足 | 某一项通过不能替代合取条件 |

G 使用三个主比较校正后的 98.333333% 区间；I 使用两个主比较的 97.5% 区间；N/W 主比较为六个配对 seed 的 95% t 区间。末期 MASK 两主比较要求 t 与联合 bootstrap 同时通过。RG 的三谱系区间为探索性描述。不能统一换成更有利的95%区间重新宣布成功。

区间跨零表示未确认方向，不表示两方法等效；未过实质门也不等于没有任何改善。

## 独立重复与权重继承

配对 seed 是同一随机初始化或旧基座分成不同实验臂，用来比较干预。六 seed×三臂通常是六组配对训练重复，不是18个相互独立的效应样本。

MC 链内部存在相关性，因此相关实验按链及时间块处理参考不确定性；同一父场的 crop、query、平移、坐标变体不能当作新的独立父场。生成图的采样 seed 也不等于训练 seed。Bootstrap 重复两万次不会创造两万个训练重复。

G、I、N/W分别从零训练。F继承A，T与R都从F0分支，Bridge只评价冻结R。J的C队列、末期MASK及RG继承I-F，但RG只以旧EMA暖启动并重置AdamW/RNG，不是完整优化器续训。详见[实验地图](README.md)。

## 公平比较与复现边界

“相同步数”不一定是相同计算量。F的辅助目标需要额外前向；N/W两臂有效token暴露不同；RG与replay有相同更新数和token预算，但物理视野不同。每个实验只能识别其实际干预，不应改写为未做过的完全因素分离。

报告给出固定最终权重、数据划分和原统计判据。学习曲线用于诊断，不用于事后挑选最好checkpoint。原始数组、协议、失败记录和源码身份保留；公开图表和摘要并不意味着所有大权重与父场都托管在GitHub。继续阅读[复现路线](REPRODUCING.md)和[数据可用性](DATA_AVAILABILITY.md)。
