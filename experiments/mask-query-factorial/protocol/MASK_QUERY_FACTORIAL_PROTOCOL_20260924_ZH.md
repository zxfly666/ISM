# 下一轮冻结方案：稀疏覆盖 × 查询覆盖的四组判别实验

日期：2026-09-24。依据：SPARSE_CONDITIONING_RESULTS_20260924_ZH.md。运行授权：NEXT_TRAINING_CONTINUATION_20260923_ZH.md。本方案在新训练/新MC生成之前写成，旧轮次不改。最多12小时，包含预检、训练、评估和统计，不强行填满。

## 1. 要区分什么

T1同时改善条件KL与大窗口生成，但同时改变了mask、查询以及辅助损失归一化。竞争解释是：H1仅补充低K覆盖就足够；H2主要是优先监督有信息的近处查询；H3两者必须联用；H4此前收益主要来自损失/监督数变化。本轮先统一辅助目标定义，再用完整2×2设计区分H1/H2/H3；若新R11−R00不再复现收益，H4或训练随机流等替代解释更值得检查，不能简单说旧结果错误。

## 2. 四个分支

| 分支 | 辅助mask | 辅助查询 |
|---|---|---|
| R00 | 普通随机mask | 64次均匀隐藏查询 |
| R01 | 同R00 | 32个最近隐藏点＋32次其余隐藏查询 |
| R10 | K∈1/2/4/8/16/32 | 64次均匀隐藏查询 |
| R11 | 同R10 | 32个最近隐藏点＋32次其余隐藏查询 |

所有辅助标签来自真实训练构型，**没有T2的物理概率标签**。网络仍是1976706参数、7层、宽128、4头的dense二维RoPE，base10000。主监督仍为原普通mask/t加权CE，辅助均为窗口等权、64个槽位等权的硬标签CE；总loss=.75主+.25辅。所有组辅助损失均不除t，避免把旧T0与T1的归一化差异继续折叠进mask比较。因此新R00不是旧T0的逐字复现对照。

每个辅助窗口的时钟统一定义为实际MASK数/N，普通mask先按原t分布(.01,1，2%全MASK)生成，再根据实际已知数计算时钟；稀疏mask也是同一规则。mask干预仍联合改变K和自然时钟分布，不能据此区分二者的单独机制。主监督保留旧定义。

64指监督抽取槽位，不保证64个独立标签：普通mask若隐藏点少于64，均匀查询可放回抽取；近处策略取min(32,H)个最近隐藏点，剩余槽位从其余点均匀抽取，不够时放回，若无其余点则从全部隐藏点抽取。K=0时不存在已知点，“近处”分支严格使用同一均匀查询。H=0时仅重抽该普通mask，保留确定性重试记录。记录唯一查询数、重复数、K、t、尺寸与物理最近距离，不能声称有效独立监督信息完全相等。

最近距离是原真实二维欧氏距离；用精确最近邻查询，等距离用固定索引打破平局。只改变loss所监督的位置，不改变attention图或推理时token。

## 3. 配对、数据与训练

6个配对初始化种子91001–91006，从旧F0最后36k状态各分4支；每支继续4000步到40k，用最后EMA，不做测试选择。训练流采用seed+10000的新随机流，与上一轮不同；四支共享全套clean/geometry/主mask/辅助两套mask和两种查询的预生成流，按1000步区块交错。原始、EMA、优化器、RNG、累积输入哈希全部保存。

训练仅使用原train分区，尺寸24/48/96，连续与真实间隔1/2/4/8各半，9216 tokens/前向，每更新两次前向。AdamW状态继承，学习率3e−5→1e−4（400步）→3e−5，clip1，EMA.999，BF16；微批次24:8、48:4、96:1。采用原val安全检查，两次连续超过本seed基座0.05则停止全轮，非有限loss/梯度立即保存停止，不剔除个别seed。

评估使用新的8链×128、L1024 MC，种子2026092411；案例种子2026092412。参考构型绝不进入训练梯度、查询选择或调参。保留相同物理点嵌入48/96/128的设计，32组新点（16局部、16随机），另20个不等距离案例是旧定义的保留测试，须标明非全新几何。6个真实标签条件bank也在新MC上重新生成。共享固定训练池和继承基座的局限保留，不能声称跨训练数据总体独立复现。

## 4. 评估与预算

每模型评估116三点案例×自然/共同两时钟，保存20种条件查询；6个真实标签bank覆盖128 K8/K32/t.5/t.95及48 t.5/t.95。

生成仅保留三种任务：W128连续96幅、W48连续64幅、s10/W48 64幅，每模型224幅，24模型共5376幅，16幅/shard。省去W96生成以保留更有判别力的四组和六种子，W96条件测试仍保留。采样器仍S0余弦平方256步、温度1、无MC校正，不因结果调整。

预检实测四组更新速度，使用上一轮同一硬件/架构/采样器的完整生成计时作为采样成本参考，并做短采样接口检查；总预测含1.2倍训练/生成安全系数、条件评估、参考准备/统计余量及已用预检时间。预计总时长超过11.5小时则不启动，不能为赶预算按测试效应删任务或减seed。硬截止从本轮预检开始起12小时；正常预计约9–11小时，以预检结果为准。

## 5. 主比较、统计与可推翻标准

两个科学主比较：A=R10−R00（均匀查询下加入稀疏覆盖）；B=R11−R10（稀疏mask下加入近处查询）。每个比较有两个终点：W128自然时钟双顺序联合KL、W128距离49–64生成G NRMSE。四项主检验使用Bonferroni对应的98.75%双侧bootstrap区间，同时提供95%区间，近似控制这一小组的多重比较；不能挑一个正面终点替代另一项。

配对6训练seed、8MC链及链内循环时间块8（主分析4000次），块4/16各1000次敏感性，生成以16幅shard配对重采样。保存每次bootstrap样本和线性对比，不把query或图像当训练种子。两个主比较的W48普通CE上界仍需≤.01，分别检验t.5/.95。对数值“无显著差异”不作等效性声明。

预定次要比较：R01−R00、R11−R01、R11−R00，以及交互R11−R10−R01+R00；报告95%区间并标明次要。报告m/m²/|m|/能量、所有G区间和order TV，不把顺序一致性作为成功门。

反证：若R10已实现全部收益而R11没有稳定额外收益，则“近处监督必不可少”不获支持；若R01也成功且R10失败，则“低K本身是关键”受挑战；若仅R11成功且交互支持，则倾向协同；若四组相近或R11−R00不复现，则回到归一化/随机流/训练预算等替代解释。均为当前干预定义下的判断，不当成神经网络内部机制已经被唯一识别。

## 6. 实现、验收与停止

新文件/新输出独立，不改上一轮源码；预检须包含：四组mask与查询匹配、隐藏查询/标签正确、最近邻与暴力距离一致、输入无测试来源、重复查询边界/K0/H0、相同输入四种标识的更新等价、确定性保存恢复、因子对比代数、短采样接口与实际吞吐。新MC失败停止，连接失效不重启，单机只启动一个本轮队列。

## 7. 自审与结论边界

贡献是对已有正面结果做可推翻的因子拆分，不提前承诺新SOTA；四组明确、标签无oracle；需承认自然时钟与K未分离、近查询改变标签相关/梯度噪声、普通mask低H可能重复抽样。新数据仅独立MC评估，训练池与基座仍共享。报告全部种子、主/次比较及不利指标。研究写作技能促使加入归一化控制、交互与不利结果；科学绘图技能用于后续四组配对图和明确区间图例，不改数值。
