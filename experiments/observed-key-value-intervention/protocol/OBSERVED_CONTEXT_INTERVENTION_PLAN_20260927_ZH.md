# J轮实验设计：观测信息通路干预能否改善大 context 条件推断？

版本：v1，整理日期2026-09-26；实验标识 observed_context_intervention_20260927。标识中的日期沿用审阅草案的种子命名，不是预约启动时间。

**状态：仅设计。未实现新模型/运行入口，未进行GPU预检，未采集新MC，未续训，未授权启动，未创建监控。** 本文与配套配置是待实施的预注册候选稿；真正的代码、环境、性能及恢复检查完成后才可冻结为运行协议。旧G/I结果、源码及独立审阅原文保持不变。

## 1. 建议与研究定位

建议采用独立审阅的A方向，但收紧为一个核心问题：

> 从同一批已学会部分几何条件推断的I-F模型出发，在训练数据、参数量和追加更新数相同的情况下，禁止未观测token作为attention的key/value，能否在未见过的H96几何上获得真实预测收益，同时不损伤原有能力？

本轮不是再证明“模型对多几个MASK敏感”，也不是证明“硬掩码能够使输出不变”。后者在明确条件下由结构保证，只是实现应满足的检查。科学价值在于：这种约束是否改善准确性，还是只得到漂亮的零漂移、甚至损害已有推断。

本轮建议只做条件推断与机制/能力控制；不新增无条件生成、不改采样器、不训练世界模型、不加真实世界数据。预计按8–10.5小时安排，硬上限12小时；**这是设计估计，必须由新实现实测替代，不能承诺12小时一定完成或取得显著结果。**

### 1.1 为什么接在I轮之后做

独立审阅核对了I轮原始预测及20,000次主bootstrap，主要结论与原报告一致：

| 已有证据 | 对下一轮的意义 |
|---|---|
| H48 K512：Fine−Span = −0.002182395，97.5% CI [−0.002994391, −0.001332232] | 有方向证据，但尚未确认超过−0.002的实质收益；不能写成全面胜出 |
| H48 K512：Fine−Random = −0.003511794，97.5% CI [−0.004369199, −0.002663934] | 真实几何对应关系确实有价值，但不能推出所有context可靠 |
| H96 K512：Fine−Random = +0.011427262，次要95% CI [+0.004856954, +0.018114463] | 更大context存在明确的指定条件反例，应在这里考验改动 |
| 固定观测、固定时钟，仅增加MASK仍可导致退化 | 信息通路干预有针对性，但尚不能唯一确定根因 |
| 训练loss/验证曲线正常，尚缺网络精确条件能力控制 | 必须分开“程序正常”“能拟合”“能外推”三层证据 |

I轮已经于2026-09-26 09:31完成计算并完成独立备份/交付，18个模型均达到12,000步。本轮不恢复旧监控，不改I轮主判定，也不重新跑旧G/I实验。

### 1.2 与老师idea的关系

老师的直接文字包括：让网络学习不同block size；把距离多样性与尺寸多样性分开验证；使模型依据真实相对距离推断；先保留dense路线，再考虑attention改动。关于“长程attention污染短程”的表述是候选解释，而非已经成立的定理。

G/I已沿dense路线完成训练几何的受控比较。本轮是对其中仍存在的context缺陷作**机制性消融**：只限制未知点进入key/value的信息通路，仍保留完整查询序列、原参数和dense张量计算。它改变了有效连接图，不能说仍是原来的全连接attention，也不应包装成老师已指定的最终算法。

对应关系：

| 老师关心的问题 | J轮能检验什么 | J轮不能证明什么 |
|---|---|---|
| 扩大context为何损伤已有局部推断 | 无新增物理观测时，数量、范围和时钟各自如何改变预测；通路限制后准确性是否改善 | MASK通路是全部历史失败的唯一原因 |
| 是否真正利用距离 | 保持真实坐标，检验低K几何响应和原H48能力是否被保留 | 任意缩放、任意点云、所有距离都能泛化 |
| 从有限context外推 | 指定H96留出几何的风险是否降低 | 完整联合分布正确、重整化规律已经学到 |
| 为世界模型提供基础 | 给出静态空间条件推断的机制证据 | 动态、动作、物理时间、长期滚动预测的成功 |

“未知位置不应改变目标”的依据有条件：物理域仍是同一个L1024零场系统；仅改变输入的未知占位表示；观测/查询选择不依赖隐藏标签；没有把新边界、新观测或选择机制的信息加进来。有限开放窗口是L1024父场的边缘，不是重新定义一个W48/W96周期物理系统。

## 3. 主张、估计对象与成功判定

### 3.1 主张账本

按theory-simulation的主张—证据设计框架组织，所有J轮条目目前为PLANNED。这里没有收敛率或置信区间覆盖定理；不虚构渐近路径或“模拟证明定理”。

| ID | 优先级 | 待检验主张 | 证据来源 |
|---|---|---|---|
| H | PRIMARY | J-O相对等量续训J-D改善H96 K512条件CE | 新独立MC、六基座配对、固定最终EMA |
| G | SECONDARY/交付护栏 | J-O也优于未经续训B0，而非仅击败退步的对照 | 同一H96 bank，B0同步评价 |
| R | SECONDARY/保留护栏 | 不明显损伤H48及连续W48能力 | 三任务×两个参照，六个保留差值 |
| M | SECONDARY/实现必要条件 | K>0、相同观测/query/t下，J-O不依赖额外MASK位置 | 8视图、I式扩展、等价单元检查 |
| C | SECONDARY/能力解释 | 网络能拟合精确小任务；最终J-O保留局部Gibbs条件能力 | 固定fixture；新背景下精确软目标 |
| L | SECONDARY | 干预之后仍对有信息几何变化作出合理响应 | 80对低K布局、绝对风险和概率响应 |

统计对象是条件于既有训练父场库、所选六个I-F基座及本固定续训配方的平均风险差。六个基座各对应一个新续训流；它们不是12次独立初始化，也不是六个独立训练数据集。联合bootstrap对基座—续训对的经验变异和新MC评价变异作近似量化，不能分别识别初始化方差与续训流方差，不能消除选择I-F作为开发基座的条件性。

### 3.2 唯一主终点H

六基座s、P=2048个父场p，每父场64个隐藏query先平均CE，再等权平均父场与基座：

\[
\Delta_H = \frac{1}{6P}\sum_{s,p}
(\overline{\mathrm{CE}}_{s,\mathrm{J\!-\!O},p}
-\overline{\mathrm{CE}}_{s,\mathrm{J\!-\!D},p}).
\]

条件固定为H96、K=512、自然t=1−512/9216，最终16k的EMA权重。单位为nat/query，负值有利。

- 双侧95%主区间上界<0：方向性收益。
- 上界<−0.005：确认超过预设实质收益门。
- 只均值<−0.005不算实质通过。
- Brier、其他clock/几何及raw权重不能替代主终点。
- H96普通标签CE不是精确条件KL。只有第8节具有解析p*的专门控制才计算精确Bernoulli KL。

### 3.3 B0进展护栏G与保留护栏R

B0：每个I-F原12k checkpoint的EMA，原dense路径，不更新参数；不是额外训练臂。

进展护栏：同一H96 K512上J-O−B0的95%区间上界<0。主门通过但该门不通过，只能说胜过固定续训对照，不能声称优于原有系统。

保留任务为H48 K512、C48 K115、C48 K1152；分别比较J-O−J-D与J-O−B0，共六个CE差。各用双侧99.1666667%区间（1−0.05/6），其上界分别须≤+0.002、≤+0.005、≤+0.005。全部六项满足才算保留通过。区间全列出，不以六项中最好的三项替代。

这是保守的同时区间规则；实际bootstrap区间只有近似覆盖，并无有限样本保证。H与G/R的合取是“完整修复”资格，不允许护栏成功抵消H失败；也不把各护栏当作新的独立主发现。

### 3.4 输出判定分层

必须分开保存：

1. 数据/实现有效性：是否配对、参考QA是否通过、M是否成立、是否全部完成。
2. 条件准确性结论：H、G、R逐项判定。
3. 能力解释：预检fixture、正式C、学习不足旗标。
4. 联合资格：有效且完整，H实质通过、G通过、六项R通过、M通过、J-O正式C三K均通过，才标记本配方下“修复证据完整”。

学习旗标仍单列，不能通过延长训练消除。即使联合资格成立，也只支持本配方、这些任务上的信息通路干预有用，不推出唯一机制或普遍外推。正式C失败不篡改已测H差值，但使“能力完整的修复”判定不通过。

## 4. 三种模型身份与信息通路

| 身份 | 初始来源 | 追加训练 | 有效key/value | 作用 |
|---|---|---:|---|---|
| B0 | 六个I-F原12k EMA | 0 | 所有valid token | 原有水平，不参与优化 |
| J-D | 对应I-F完整12k状态 | 4,000步 | 所有valid token | 等数据、等追加训练对照 |
| J-O | 同一个I-F完整12k状态 | 4,000步 | K>0时只允许已观测自旋；K=0回退 | 信息通路干预 |

共12个续训分支、6个冻结基座；最后正式评价18个模型身份。

### 4.1 唯一结构变化

token：0/1为已观测自旋，2为MASK，3为PAD。定义：

\[
O = V\land[(x=0)\lor(x=1)],\quad
K_{\rm allow}^{D}=V,\quad
K_{\rm allow}^{O}=
\begin{cases}
O,& \sum O>0\\
V,& \sum O=0.
\end{cases}
\]

V是valid mask。分支判断**逐样本**执行，并在全部7层保持一致。K_allow只屏蔽attention的key/value来源；所有有效位置仍保留query、残差、逐token MLP和输出。不能用O替换V。

实现保持完整N个query/key/value张量；不压缩观测序列，不引入新参数、不改batch或监督槽位。无偏置qkv、q/k LayerNorm、2D RoPE、时间条件和输出头均不改。使用与原实现一致的加性attention bias：允许项0，禁止项−∞，与q相同dtype。

PyTorch 2.7的SDPA支持加性掩码；不同mask/输入可能选择不同内核并出现数值差异，因此“参数相同、token预算相同”不等于实际运行时间或FLOPs完全相同，必须实测和披露。[官方SDPA说明](https://docs.pytorch.org/docs/2.7/generated/torch.nn.functional.scaled_dot_product_attention.html)

### 4.2 为什么固定信息下应不变

K>0时，观测点每层只读取其他观测点；隐藏query只读取观测点并保留自己的逐token状态。其他MASK节点无法向观测点或该query传回信息。因此在相同E、观测值、query坐标、t、参数及逐样本计算下，增加其他MASK节点应不影响该query输出，仅可能有浮点误差。

这是结构性质，不是新的实证发现。它还排除了原模型使用未知节点作中间计算的可能路径；这些节点虽然不提供新增物理观测，却可能有计算作用。故准确性可能升也可能降，不能把消除路径本身当成成功。

K=0回退后不承诺该不变性。自然t随着N改变时也不承诺不变；时间MLP仍可引入表示依赖。不存在“J-O固定t不变，因此联合生成正确”的推论。

### 5.2 每臂4,000更新，其他训练设计与I相同

32步一个周期，W16/24/32/48×continuous/train_gap共8格；每格3普通更新、1稀疏更新。每次18,432 token；对应batch为72/32/18/8。

- 普通更新75%：t均匀分布于[0.01,1]，另2%强制全MASK；损失为总masked CE/t除以18,432。
- 稀疏更新25%：每窗K从1/2/4/8/16/32等概率取值；全更新共512个隐藏query槽位；先选query，再选不重叠观测；query CE平均，不除t。
- train_gap沿用I整数间距1/2/4/8的多重集；D4和自旋翻转不变。
- 同seed两臂每一步的父场、origin、物理轴、增强、token、mask、query、t和监督权重必须逐项/逐步hash相同。唯一不同是内部key掩码及其学习后参数。
- 全部4,000步包含125完整周期：每臂3,000普通、1,000稀疏更新，130,000次窗口暴露，73,728,000 token，512,000稀疏监督槽位。
- 12臂共48,000更新、884,736,000 token；不把共享数据暴露数称为独立物理样本数。

### 5.3 优化与恢复

AdamW β=(0.9,0.95)，weight decay=0.05，gradient norm clip=1；EMA decay=0.999。保留原优化器历史，仅按预定续训计划重新设lr：

- 第s=1…400步：3e−5+(1e−4−3e−5)×s/400。
- 第s=401…4000步：3e−5+0.5×(1e−4−3e−5)×[1+cos(π(s−400)/3600)]。
- 每臂到续训4k即停；全局step=16,000、优化器step历史继续，不能仍误标为4k新模型。
- 两臂都从原EMA继续累计；4,000步后原EMA的直接残留系数约0.999^4000=1.83%。这是共同配方，不为J-O另重置EMA。

按1,000步块交错执行两臂和六seed。固定顺序：每块seed升序；(seed序号0…5+块序号0…3)为偶数先D后O，否则先O后D，避免某臂总在同一时段。保存完整可恢复last；2k保存诊断EMA；4k保存不可覆盖完整final。自动失败重启禁用；确需恢复时先诊断、核实原deadline和锁，不能把恢复当新增预算。

### 5.4 验证与学习不足标记

在追加0/2k/4k执行同一套8个旧验证库bank，各64父场、64query：C48 K2/32/512/115/1152，U48 K2/32/512。新验证流固定，父场按两条val链均匀取32个。只用于轨迹/诊断，不挑checkpoint、不改lr。

## 7. 分离数量、空间范围和时钟

### 7.1 2×2×2八视图

256个固定参考父场，每父场共享K32观测、64query及标签。使用整数点云表示，N为**包括E、query和其他MASK在内**的有效token总数：

- N ∈ {576,2304}。
- 背景域边长D ∈ {48,96}。
- t ∈ {1−32/576,1−32/2304}。

物理坐标采用共同0…95坐标系。D48域是[24,71]²，D96域是[0,95]²；它们的坐标极差分别47、95，不把“边长D”和“跨度D”混称。

具体构造冻结如下：

1. 在[36,59]²这个共同24×24内区，均匀抽取96个不同位置，前64个为query，后32个为E。
2. 每个D强制加入该域两个对角角点作MASK，以固定两个坐标轴的极值；角点不与E/query相撞。
3. 对剩余可用整数点以固定、与自旋无关的随机优先级排序，填满N；每个D内N576集合是N2304集合的子集。D48、N2304恰为完整48×48点集。
4. 不要求不同D之间点集嵌套；改变D必然同时改变未知点的具体布局。这是“背景范围/布局”干预，不声称只识别某个单独RoPE频率。
5. 所有视图沿相同parent/origin读取E值与query标签；其余点始终MASK。query以物理坐标身份映射，不能直接沿用改变N之前的扁平索引。
6. 输入适配为[B,1,N]及[B,1,N,2]；不借用要求方形W的bank校验函数。另验证方形输入与展平输入逐query等价。

报告八视图CE/Brier与基准视图(N576,D48,t576)的配对风险差、mean/max |Δp|；分别计算固定t的N效应、D效应及交互，以及仅改t的效应。J-O固定E/query/t时最大概率差须≤2e−5。概率更稳定却CE更差必须并列展示。

这是人为构造的表示压力分布，不是对“自然W96任务”的替代，更不是任意真实点云应用的证明。

## 8. 确认模型有能力：解析正控制与负控制

### 8.1 精确目标的范围

当query的四个**真实单位距离最近邻**全部可见时，零场最近邻Ising的条件概率是

\[
p_*(s_q=+1\mid E)=\sigma(2\beta_c\sum_{j\in NN(q)}s_j).
\]

由Hamiltonian中含s_q的四条边得到：两种query取值的条件权重比为exp(2βcΣs_j)；固定邻居后，其他已知或未知点的因子在该比值中消去。于是可用精确软目标，无须MC来估计这个条件概率。

此式不适用于gap3/6下的四个“token邻居”，也不是给整个H96 bank提供精确oracle。计算Bernoulli KL(p*||qθ)与Brier的解析期望；正式普通任务仍用真实隐藏标签评价CE。

### 8.2 预检小任务拟合：只用固定scratch

两个同初始化scratch模型，原dense与observed-only各1024更新；seed2026092700，W8，query=(3,3)，四最近邻可见、其余MASK，t固定1−4/64。16种邻居符号模式等权，每次batch16完整枚举。

损失是query上的soft BCE均值，不加扩散1/t权重；AdamW/clip同主配方，lr前64步从0线性到3e−4，之后余弦到3e−5。评估最终raw权重而非EMA。两臂均须16模式最大KL≤0.01且全部有限。

它是固定小任务可拟合检查，不证明任意几何可学。失败意味着该实现/配方的能力尚未确认：记录并停止正式阶段，不加步、不挑另一个seed或阈值直到通过。两个scratch不继承到正式12臂，预检计算计入12小时。

### 8.3 正式精确条件迁移诊断

64个新参考背景：每链保存帧0/32/64/96，共4/链。每背景query在连续W48的(23,23)，映射到W96为(47,47)。四个物理最近邻必可见；K4/32/512，额外K−4观测从W48内非query/非四邻居位置取，按固定排列嵌套。所有额外观测位置和值在扩展前后不变。

每背景枚举16种邻居符号；只改这四个值，目标随之改为p*。**不能保留原父场query硬标签。** 这些干预背景不按自然Ising出现概率加权；每模式等权是能力压力测试，不冒充自然分布CE。

三个视图：W48自然t48、W96固定t48、W96自然t96。18模型全部评价。每个模型/视图/K先对16模式求父场平均KL，再按父场/基座聚合；模式与同背景扩展视图都不是独立重复。

K=4时没有额外背景观测，同一模型的16模式输入在64个父场之间实际上相同；其MC背景变异应为零，只能从六个模型身份评估经验变异，绝不能将重复拷贝当64个新增独立能力样本。保留统一数组身份以便审计；K32/512才引入不同背景观测。

- J-O的C48视图三个K，各用98.3333333%区间（1−0.05/3），上界≤0.01才算正式能力门C通过。
- 对J-D与B0报告同样的能力检查，但不以它们失败为理由删除J-O结果。
- 同时保存每模式平均、每背景最大KL、最大概率误差、解析Brier及W96扩展差；平均合格不能掩盖某个模式坏。
- C失败与主H失败是不同信息；C通过仅说明特定局部条件能力，不证明H96优化充分。

### 8.4 程序等价与信息负控制

预检全部检查：原模型与J-D同权重前向；完整状态恢复后下一步更新；token/坐标/valid同步置换再逆映射；共同整数平移；插入valid=false的PAD；批次与逐样本前向；混合K=0/K>0批次的逐样本回退；隐藏query始终输出且不泄露标签。

FP32概率容差2e−5。平移检查固定为(7,−11)及(−13,5)，不随错误调容差；位移只改共同坐标原点。主恢复检查同环境同batch应精确或满足事前记录的数值契约；确定性环境、CUBLAS_WORKSPACE_CONFIG=:4096:8和内核身份纳入预检记录。

J-O的MASK数量/背景布局负控制不变性不通过是实现有效性失败，不解释成科学反例。不能把PAD等价通过移作MASK等价通过，两者含义不同。

- 不报告“信息利用百分比”，也不让低K成功替代H96主结论。

## 10. 统计实现、精度与失败解释

### 10.1 联合重采样

H/G/R：20,000次。共同重抽6个基座—续训对、16条MC链，并在每条被抽链内循环块采样。2048主库块长8保存帧；块4/16各10,000次敏感性。C48 256子集按选中帧序列块2，块1/4各10,000次；不能把该块2称为两帧原始MC间隔。

所有比较臂和同一物理信息的视图共享bootstrap权重；每父场64query先平均。保留逐seed、逐链、seed-only、MC-only各10,000次，配对t和留一基座分析。主判定只用预设joint主区间，敏感性不同则如实警告，不挑最窄区间。

机制/扩展：10,000次、256子集块2及1/4敏感性；精确条件：10,000次、64背景选中序列块1、块2敏感性。16模式先平均，不当作16个独立MC重复。低K联合2,000次、2048父场块8；固定80个布局不另当随机总体抽样。

除已定义主门/保留门/能力门外，区间为点态95%、次要/诊断性质；不声称所有大量对比家族均有5%错误率控制。

### 10.2 精度规划

I的H96 F−R联合bootstrap SD约0.003386，固定MC下六seed均值SE约0.003266；这是不同对比，仅作风险警示。不能把H48的约0.00037迁移到H96，亦不能认为父场从256到2048就能让总SE缩小√8倍。

J的同基座配对可能降低差值方差，但未实测。若真实差为−0.010、要以双侧95%上界确认<−0.005，正态近似80%功效要求SE约≤0.00178；六seed用t临界值的粗规划更严，约0.00146。这不是本设计已达到的功效。优先目标SE≤0.002仅为精度标尺，超过就报告不足，不追加seed或父场。

报告joint/seed-only/MC-only bootstrap SD，及固定10组重采样的区间端点数值稳定性。bootstrap次数是数值重采样次数，不是新增独立科学样本；不通过扩大bootstrap次数掩盖六基座不足。

真正检验区间覆盖率需要许多独立训练库/模型/MC的外层重复，本12小时方案不包括它。因此不用“bootstrap已保证95%覆盖”之类表述。配对规则、真值来源和设计透明性参考ADEMP方法，但这里不是一篇渐近推断方法论文。[Morris等，2019](https://doi.org/10.1002/sim.8086)

### 10.3 非显著与等效

区间跨0但仍容许−0.005或更大收益：证据不足，不是无效。只有预设95%区间完整落入(−0.005,+0.005)，才可描述为在该容差和本配方下较窄的相近表现；这是保守的区间描述，不另冒称完成一套经校准的TOST程序。不向老师整个idea作无效判决。

在正式冻结门，单位均为秒：

\[
\widehat T_{\rm total}=E+\max(1.25T,1.25M)+1.25(F+L)
+\max(2700,1.25A)+1.25B+900+1800.
\]

- E：自t0已用实际时间。
- T：剩余训练、验证、checkpoint本地I/O；不含正式评价。

- A：统计、绘图及实际视觉核验；最少2,700秒。
- B：未完成的CPU打包/传输/包内SHA核验；与L的本地预测写盘分开，不能双计，也不能漏计。
