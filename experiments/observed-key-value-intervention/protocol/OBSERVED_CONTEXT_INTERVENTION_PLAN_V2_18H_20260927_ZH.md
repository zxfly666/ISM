# J轮18小时版：从零训练主检验＋已有模型续训对照

版本v2；设计日期2026-09-26；实验标识observed_context_intervention_18h_20260927。标识日期不是预约启动时间。

**当前仅修改设计，未实现新科学运行入口、未做GPU预检、未启动MC/训练、未创建监控。用户“预计时间大概在18h左右”在这里解释为：目标16–18小时，暂按18小时硬上限规划，不默认为20小时授权。**

旧12小时v1文件及原独立审查草案完整保留。由于v1从未启动，本次是在看到J结果之前调整科学设计，不是运行中延长预算或改主终点。本v2是当前建议方案；启动仍需用户明确指令，随后通过新实现/能力/预算检查。

## 1. 多出来的预算用于什么

不是只把原来的4k续训延长，也不以花满18小时为目标。新增计算重点回答：

> 限制未知token的信息通路，是只对已经训练过的I-F模型有帮助，还是从零训练时也能改善大context条件推断？

原v1的主要限制是继承旧模型：失败可能包含适应不足，成功也可能依赖已有表征。本版保留这组诊断，并新增六对从零模型，固定训练24k。**从零组成为唯一主检验；续训组是预先固定的辅助对照，不能在主检验失败后代替主结论。**

同时扩大新MC评价库到4096父场，降低部分评价噪声；它不能消除六个训练seed带来的不确定性。依然不做新无条件生成、不变更采样器、不扩GPU/CPU资源、不加入真实世界或世界模型任务。

## 2. 固定模型与两批训练

共同架构：宽128、4头、7block、MLP ratio4、2D RoPE base10000、dropout0，1,976,706参数。token0/1为观测自旋，2为MASK，3为PAD。D允许所有valid点作为key/value；O在每层只允许观测自旋作为key/value，所有valid query、残差和逐token MLP保留。K=0逐样本回退到原dense规则；key mask和valid mask不能混用。

仅改变信息通路，不加参数、不压缩N、不改每步token预算。原v1关于整数点集、无查询泄露、FP32容差2e−5、恢复等价、PAD/置换/平移检查等规则全部保留，详见第11节的继承范围。

### 2.1 续训组C：复现原v1的受控问题

- 六基座I-F seed92601–92606，完整12k状态；两臂C-D/C-O。
- 续训数据seed92701–92706；同基座两臂逐步共享物理数据、mask、query、t、增强及监督权重。
- 各4,000步，到全局16k；原raw model、EMA、AdamW矩及计数均恢复，不重置优化器。
- lr从3e−5在400步升至1e−4，其后3600步余弦降至3e−5。
- 0/2k/4k执行8类旧val验证；2k保存EMA，final完整可恢复。
- 这批仍是六个“基座—续训流”配对重复，不是12个独立初始化。

### 2.2 从零组S：新增唯一主检验

- 六个新初始化seed92711–92716；独立数据流92721–92726。冻结前复核命名空间未被正式运行使用。
- 每seed创建S-D/S-O同初始权重；使用相同训练数据流。没有加载I/G权重、EMA或优化器。
- 每模型固定24,000步，12个模型共288,000更新。不在12k看新测试后决定是否继续。
- AdamW betas(0.9,0.95)、weight decay0.05、clip1、EMA0.999、BF16前向/FP32损失不变。
- lr前1500步从0线性升至3e−4；第1501–24000步余弦降至3e−5。两臂完全相同，无测试调参。
- 在0/8k/12k/16k/24k执行8类旧val验证；8k/12k/16k保存EMA。最终24k EMA是主评价权重。
- 12k EMA在全部最终模型锁定后，只评价四个核心bank；不跑全套机制诊断，不替代24k主终点。
- 最终保存模型、EMA、优化器、全部RNG状态、身份与训练日志；检查同seed两臂初始化及全程配对。

**12k快照是同一24k学习率计划的中点，不是独立训练的一组12k模型，也不等价于旧I轮12k终点配方。** 12k→24k反映该预定训练轨迹上的变化，不能纯粹归因于“只多了训练步数”。

24k是固定投资，不是已证明足够收敛。逐验证单元标记最终CE≥ln2、或16k→24k仍改善>0.005；续训组仍检查2k→4k。旗标只限制解释，不能触发加步。

## 4. 预注册判定：不混合两批，不挑赢家

### 4.1 唯一主检验H_S

在H96 K512自然时钟，比较六个从零seed的最终24k EMA：

Δ_S = mean_seed,parent(CE[S-O] − CE[S-D])。

每父场先平均64 query。双侧95%区间上界<0为方向成立；上界<−0.005为实质通过。仍用负值表示O更好。Brier、12k快照、C组或低K响应均不得代替该主终点。

从零组保留门：H48 K512、C48 K115、C48 K1152的S-O−S-D三项，各98.3333333%区间，上界分别≤+0.002、≤+0.005、≤+0.005。三项全部过才算原任务保留。

本版“从零通路干预证据完整”要求：全核心数据有效完整；H_S实质门通过；S组三个保留门通过；结构实现M通过；S-O的正式Gibbs C48三个K能力门通过。所有失败/学习flags照常报告。

### 4.2 续训结果：预先声明的辅助桥接，不是第二次主抽奖

报告C-O−C-D的H96差值及95%区间，沿用−0.005作为描述性实质标准。C-O−B0上界<0才支持优于原有系统；原三保留任务各对C-D和B0比较，共六项99.1666667%区间，阈值与v1一致。

C组可单独给出“固定续训配方下修复资格”，但它不能挽救H_S失败，也不能和S组平均出一个更好看的主结果。不宣称两批拥有独立参考的不确定性。

B0与S组初始化不匹配，且训练预算不同：其绝对CE可同表描述，但不能按seed编号硬配对，也不能据其差值声称纯架构因果收益。

### 4.3 两批差异及训练轨迹

预定次要结果：

- Δ_S−Δ_C：两批各自的O−D差值再比较。MC重采样权重共用，各批seed独立重抽。解释为对两种完整训练方案的效应差，不是纯初始化效应。
- S各臂12k→24k核心CE变化；O−D差值在两个快照的变化。同seed、同父场配对。
- 不能用“C显著、S不显著”直接断言两批效应显著不同；必须看差值之差及其区间。
- 12k发现更好也不换主checkpoint；全结果报告，包括24k若退步。

更多计算不是让显著结果变得必然。本版仍只有六个S组初始化重复；不能把两臂相加成12个独立seed，亦不能把C和S合并成12个同分布重复。

## 5. 必需机制与能力控制

原v1的全部核心控制保留，正式最终模型从18个身份扩为30个：6 B0＋12 C final＋12 S final。S组12k只评核心bank，不运行以下全套控制。

1. 数量×背景范围×时钟的八视图：256父场、K32、64query，N576/2304、D48/96、两固定t；整数点集/角点锚定/嵌套规则不变。固定E/query/t的O不变性只是结构检查，必须并列准确性。
2. I式W48→W96中心扩展：K32/512、256父场、三视图（小自然、大固定钟、大自然钟）。
3. 预检精确Gibbs小任务：两个scratch网络、W8、16邻居模式、各1024步；raw终点最大模式KL≤0.01；失败不临时加步。
4. 正式解析条件能力：64背景、每链帧0/64/128/192；16邻居模式×K4/32/512×三个C48/C96视图。修改邻居后用解析软目标，不沿用原query硬标签。K4的64背景输入重复，不能虚增独立信息量。
5. O组各自正式能力门：C-O与S-O分别计算C48三个K的98.3333333%区间，上界≤0.01；两组门分别解释，不能挑较好一组替代另一组。
6. 低K：I冻结80对蓝图不重选，新4096父场×256共同平移；原始计数4096×80×2×8；pair条件与相同有效几何池化参照分列，保留rare/undefined，不报信息利用百分比。
7. 同输入/原D等价、PAD、置换、平移、query隐藏、K0逐样本回退、恢复下一步检查均不省略。
8. 四核心bank的固定p=0.5及可见均值CPU基线照常报告，不作为新的训练臂。

无新生成任务，MC参考裁片不算模型生成；固定t不变不代表自然t不变，更不代表完整联合正确。

## 6. 统计层级、精度及限制

主检验20,000次joint bootstrap：六S-seed配对×16链×链内循环块8（256保存帧序列）。块4/16各10,000次；seed-only/MC-only、配对t、LOO照常保存。C组同方法单独分析，不混进S主区间。

256子集按选中序列块2，块1/4敏感性；现在相邻选中帧相隔16原始保存帧，不能称与主库块8等同。64背景的解析控制按选中帧序列块1及块2敏感性；模式先在背景内平均。低K联合2000次、主库块8；其他机制控制10,000次。所有同物理输入视图共享权重。

六seed的经验不确定性仍可能主导区间；4096父场不会自动保证0.002或0.005效应有80%功效。继续报告joint、seed-only、MC-only SD和固定分组端点稳定性，不增样到显著。bootstrap不自动提供有限样本覆盖保证。

只评估一个24k学习率方案，不做超参数搜索；没有新训练数据集外层重复。负结果的范围是本架构/训练库/配方，不能宣判老师全部idea。纯结构性质、能力检查和准确性改进继续分开，按theory-simulation的主张—证据框架组织，不以一项通过替代另一项。

## 8. 为什么预计接近18小时，而不是随便报时长

### 8.1 只用历史记录做规划，不冒充新测速

I轮216,000更新训练完成用3.283192h；按更新数线性外推，本轮336,000更新约5.107h。它不是新O掩码速度实测，不保证内核/CPU竞争相同。

I轮2048参考用4891.1846秒；4096样本以简单倍数规划约2.72h，正式以生产计时为准。采样不与训练简单相加：它与训练并行，取关键路径并计入资源竞争。

FP32输入前向粗规划使用I配置中记录的历史G预检值：W48约0.0079966秒/输入，W96约0.0289883秒/输入；N576也按W48计，是保守代理。历史I预测I/O5970.01秒/668160个条件输入只用于粗比例代理，文件数量、压缩和新格式均可改变真实耗时。

这些代理配合0.5h预检、0.13h检查点I/O、0.75h导出/传输假设，代入下式得到约**17.17h**。若预检已用0.75h，同其他假设约17.42h；接近门槛说明必须实测，不能宣称已具备足够余量。完整假设和分项保存在静态检查回执，不把这个算术结果写成budget_passed。

### 8.2 新固定时钟

目标16–18h；保守启动门17.5h；暂按18h硬截止。首次本轮GPU预检或新MC开始的较早时间为t0，deadline=t0+64800秒；等待、断线、预检失败处理均计时。纯代码编写与本文设计不计入计算窗口，因此不能承诺“从现在起18小时交付”。

预测式沿用v1的不重叠口径：

E + max(1.25T,1.25M) + 1.25(F+L) + max(2700,1.25A) + 1.25B + 900 + 1800。

其中T为剩余训练/验证/检查点本地I/O，M为剩余并行MC/QA/低K表，F为剩余正式前向与bank构建，L为预测本地写盘，A为统计/图/实际视觉检查，B为导出/传输/包成员校验，最后两项为联合manifest复核与额外安全余量。必须避免把验证前向同时计入T和F，或把传输重复计入L/B。

阶段规划而非相加保证：

| 阶段 | 预算意义 |
|---|---|
| 预检/恢复/能力fixture/全类型计时 | 约0.5–1h；完整计入已用E |
| C＋S训练与验证 | 原始历史比例约5.2h起，另考虑新掩码和CPU竞争 |
| MC/QA/低K表 | 约2.7h代理，与训练并行；拖尾不能漏 |
| 827,520输入对应前向与本地I/O | 按类型实测；历史代理约6h量级，已包括中途验证 |
