# 实验精读与汇报路线

本项目研究：在临界 Ising 上，让模型接触不同的上下文尺寸和真实物理距离，能否改善未见布局上的条件推断，并进一步支持正确生成和跨尺度迁移。

准备汇报时，先掌握 G、I、N/W、RG 四组重点，将Basic作为理解N/W的必要桥梁，再用生成实验限定结论。2026-11-15已将这五篇整理为详细学习稿：每篇包含构造例子、完整对照、数据与真值、训练流程、统计判据、读图、反例、自测和证据地图。科学结果没有重算。

研究登记有14个已完成单元，其中包含冻结诊断和探索先导；另有一个只完成预检、未正式启动的方案。这个数量不是14次独立训练复现。

## 详细版怎样读，才能真正掌握

不要先从几十份JSON或训练日志开始。每篇按以下三遍阅读：

1. **建立问题**：读开头结论、动机、对照与构造例子，自己画输入和组别。
2. **理解证据**：读数据划分、主指标、原门槛及原图；指出图上点与区间的单位。
3. **检查掌握**：不看正文回答篇末自测，再用证据地图核对不确定的数字。

| 材料 | 建议精读时间 | 必须留下的笔记 |
|---|---:|---|
| 方法与指标 | 20–30分钟 | W/L/K/M、MASK/PAD、CE/KL、训练seed/MC链的一页词表 |
| G | 35–45分钟 | 五组对照；H1/H2通过、H3未决及H96反例 |
| I | 30–40分钟 | 亲手写一个F/S/R坐标例子；P1方向与实质的区别 |
| Basic | 25–35分钟 | 单value attention盲点；精确枚举；K4扩容结果 |
| N/W | 40–50分钟 | 八点边界腔体图；N/W有效尺寸；平均与最坏误差两张图 |
| RG | 35–45分钟 | 多数投票与三臂更新量；三谱系主差；粗学习与细代价 |
| 闭卷串讲 | 15–20分钟 | 每篇用“问题—对照—结果—限制—下一问”讲两分钟 |

五篇正文约2小时45分至3小时35分；加方法入门和闭卷复述约3小时20分至4小时25分，不含休息与其余实验回顾。时间是阅读建议，不是保证；卡在腔体或统计判据时应暂停画图，不必强行赶完。

五篇都用同一套阅读结构，但不是同一套实验：G/I主权重是12k EMA，Basic/N/W是固定final raw，RG是旧I-F EMA暖启动后固定终点EMA；看见同样模型宽度不能据此认定训练身份相同。

### 每篇只记一句完整结论

| 实验 | 一句不遗漏边界的结论 |
|---|---|
| G | 尺寸和间距覆盖在各自指定任务上有收益，细排列相对跨度的原主收益未确认，并非所有共同外推任务协同。 |
| I | 正确对应在H48 K512胜过随机对应；相对跨度只有方向证据，H96有反转。 |
| Basic | 原dense可学会固定小任务，但特定O结构有盲点，学会后扩容仍会失准。 |
| N/W | 宽尺寸训练显著降低平均扩容误差，但W在主任务的最坏能力门仍0/6。 |
| RG | 粗任务学习有一致探索信号，细W96迁移未确认，且存在细任务代价。 |

## 以ISM为主的四十分钟汇报建议

下表侧重ISM。若需要完整展开合作者工作，使用[详细计划第七节](../docs/PROJECT_REACTIVATION_AND_ADVISOR_REVIEW_PLAN_20261104_ZH.md#七明日40分钟汇报按问题推进不按日期报流水账)的双仓库版本：给合作者Stage 0/1/2单列7分钟，相应压缩ISM各段；不在下表之外额外加时。

|---|---:|---|
| 问题起点与共同方法 | 6分钟 | L128偏差；条件与生成的区别；尺寸与距离示意 |

## 讲每个重点实验的固定顺序

1. 前一轮留下了什么问题，为什么现有证据不能回答它。
2. 对照组分别改变什么，哪些输入和训练条件配对。
3. 数据与测试怎么分开，主权重和主指标怎样预先固定。
4. 图的横轴、纵轴、点、误差线分别代表什么。
5. 正结果支持哪一句话，反例禁止哪一种推广。
6. 下一步需要补的证据是什么，而不是简单增加预算求显著。

共同方法只讲一次，各轮说明差异。尤其不要把后期dense网络与早期轴向模型混成同一个架构，也不要把RG暖启动称为从零训练。

## 汇报前自检

- 是否把G的间距覆盖收益误写成纯RoPE机制证明？
- 是否把I的改善方向与实质门混为一谈？
- 是否同时呈现N/W的平均收益和0/6绝对门？
- 是否在RG里明确三条旧谱系、已查看的参考与物理视野差异？
- 是否保留T的正结果，同时交代R、Bridge和末期MASK的限制？
- 是否把未执行的size×clock方案当成已回答的问题？
- 是否把旧Stage2B大效应、旧GO标签或采样seed数量误当作当前确认？
