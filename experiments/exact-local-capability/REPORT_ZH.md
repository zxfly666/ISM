# Basic｜先分清结构盲点、学得会和扩容后仍准确

> 一句话结论：原dense模型经过专门精确目标训练，可以学好本轮4×4局部任务；特定observed-only结构在K1等构造中存在几何盲点；即使dense在小任务上通过，扩到8×8后仍明显失准。这三件事同时成立，不能压缩成“模型行”或“模型不行”。

实验：basic_capability_stages12_20260928，完成于2026-09-28。本文为2026-11-15新增的详细学习稿，依据已有冻结协议、真值构造和完成摘要，不新增训练或修改结果。

## 阅读目标

建议用25–35分钟精读。本篇是理解N/W的桥梁：你要能解释为什么先做一个很小、答案精确的任务，比立即扩大训练更能定位问题。

读完应分清四句话：

- 一个结构在某类输入上**不可能区分**正确答案。
- 一个结构理论上允许响应，但某次训练**没有学会**。
- 一个专门训练配方在固定小任务上**确实学会**。
- 学会小任务，并不保证在外围增加未知位置后**仍然准确**。

这不是四个同义表述，也不是四个独立的新训练实验。

## 1. 为什么需要这轮诊断

J曾尝试改变attention的K/V来源，使隐藏query更多依赖已观测自旋。某些表示不变性有所改善，但条件能力并未整体合格。此时至少有三种解释：

1. 结构本身丢失了必要信息，再训练也不能解决某些构造。
2. 结构可以表达，但原混合任务、损失或优化配方没有把能力学出来。
3. 标签、评价或元数据有错误，导致对能力的误判。

Basic把这些可能性分别检验，而不是把所有失败都归因为“训练不够”或“attention不可行”。

### 实际做了什么

| 部分 | 问题 | 实际动作 | 是否新训练 |
|---|---|---|---|
| E1 | 距离信息是否有通路影响输出 | 同参数D/O、非零输出头的结构与有限构造检查 | 否；不训练O |
| E2 | 原dense能否拟合真实精确条件概率族 | 3个fresh D，各2048次CPU更新 | 是，唯一新训练部分 |
| E3 | 原J混合配方是否也具备该能力，旧标签是否有误 | 只读复核J的36份预测、3个bank和12个旧包 | 否 |
| E4，次要 | 小任务学会后，扩容会不会破坏准确性 | 固定E2 final raw，把K4任务嵌入8×8 | 否；是E2模型的迁移评价 |

“第一、二阶段”是整体工作阶段；E1/E2/E3/E4是诊断问题编号。E4不表示擅自启动了另一轮架构改造或大规模外推训练。

## 2. D与O有什么结构差别

D是原dense：有效MASK与已观测位置都可参加attention。O是J中的特定observed-only实现：K/V来源限制为观测点，几何坐标主要通过Q/K中的RoPE进入，而value及初始token内容不直接携带坐标。

一次attention聚合的核心形式为：

```math
h_q=\sum_{j\in E}\alpha_{qj}v_j,\qquad
\sum_{j\in E}\alpha_{qj}=1,
```

其中E是允许被读取的观测位置集合。

### 为什么K1会暴露O的盲点

K1只有一个可见自旋。在O这条通路中，只有一个允许的value，归一化权重恒为1；改变距离即使改变Q/K打分，也不会改变加权结果。

更一般地，在相关构造中若所有允许的value都相同，则：

```math
\sum_j\alpha_{qj}v=v.
```

几何可以改变权重，却不能改变聚合内容。这需要结合本实现“位置不进入value、相同符号的表示保持相同”等条件理解；不是关于所有attention架构、所有K或所有位置编码的普遍不可能性定理。

### 为什么不能用零输出头检查这件事

原模型输出头零初始化时，无论中间表示如何变化，输出都可能恰为.5。此时平移、重排、扩容“完全不变”可能只是恒定输出的假象。

E1在丢弃副本上使用非零输出头，观察几何变化是否能传到概率；这些副本不作为E2训练初始化，也不要求随机网络预测准确。E2仍从原始fresh初始化开始。

### 有多大的不可避免误差

固定符号的K1条件表中，不同几何的真实概率范围约为.176760。如果某类结构对这些情况只能输出同一个数，那么即使选最佳常数，其最大概率误差也至少是范围的一半：

```math
\min_c \max_i |q_i-c|
\geq \frac{\max_i q_i-\min_i q_i}{2}
=.088380.
```

这已经超过预定.05能力门。E1中O确实不显示K1距离敏感性，而D有数值响应。

D“有响应”只说明必要的信息通路没有完全堵死，不说明响应大小或方向正确。O这个特定反例也不否定所有observed-only设计，尤其不能替代对其他位置注入方式的分析。

来源：[结构摘要](evidence/structural_summary.json)、[原方案](protocol/BASIC_CAPABILITY_STAGE12_PLAN_20260928_ZH.md)。

## 3. 精确真值从哪里来：不是用更多MC近似

有限物理系统为4×4开放边界、最近邻耦合J=1、外场h=0，取：

```math
\beta=\frac{\log(1+\sqrt2)}{2}.
```

这里采用二维无限系统临界参数值，不宣称有限4×4系统自身存在热力学奇点。

16个自旋只有2¹⁶=65,536种完整状态，可全部枚举。对状态s赋予权重：

```math
w(s)=\exp\left(\beta\sum_{\langle i,j\rangle}s_i s_j\right).
```

给定可见集合E及其符号，查询q取+1的概率为：

```math
P(s_q=+1\mid s_E)
=\frac{\sum_{s:\,s_E\text{匹配},\,s_q=+1}w(s)}
{\sum_{s:\,s_E\text{匹配}}w(s)}.
```

因此目标是一个精确概率，而不是单张样本的0/1答案。使用精确软标签训练可以把“参考采样噪声”从这轮诊断中拿掉。实现还用独立逐行转移矩阵等检查交叉核对真值。

**没有新增MC，没有整图生成。** 精确表没有MC抽样误差，但模型初始化、有限训练和任务选择仍有局限。

## 4. K1、K2、K4分别检验什么

query取4×4的四个内部点；query始终隐藏。

| 任务 | 构造 | 总记录 | 训练 / 留出 | 检验重点 |
|---|---|---:|---|---|
| K1 | 其余15点选1个可见，遍历两个符号 | 4×15×2=120 | 80 / 40 | 单观测下的几何与边界依赖 |
| K2 | 其余15点选2个，遍历四种符号 | 4×105×4=1680 | 1152 / 528 | 两观测组合及几何依赖 |
| K4 | 查询的4个单位最近邻全可见，遍历16模式 | 4×16=64 | 全部用于能力拟合 | 基本局部Markov条件公式 |

K1/K2按完整D4旋转反射轨道划分，等价布局及同布局的全部符号不跨训练和留出，减少“已经见过同一个模式的旋转版本”的泄漏。

K4的64条是拟合条件，不是64条独立测试；它的迁移检查是之后的8×8嵌入。每个任务内按条件行均匀加权，不按这些观测模式在自然Ising分布中的出现频率加权。因此这里检验的是固定条件表能力，不是自然总体风险。

### K4为什么简单，也为什么还值得做

当4个最近邻全部可见时：

```math
P(s_q=+1\mid s_{\partial q})
=\frac{1}{1+\exp\left(-2\beta\sum_{j\in\partial q}s_j\right)}.
```

它只依赖4个邻居的自旋和。模型可能通过正负计数解决这个任务，不必学会更一般的排列依赖。因此K4通过是基础能力证据，不是充分的几何识别证据；后续N/W使用更难的G8腔体来避免仅计数就能完成。

K1/K2缺少完整邻域屏蔽，目标涉及其他未知自旋的边缘化，还受到有限边界影响。不能把它们的4×4概率表未经重新推导直接作为8×8或L1024真值。

## 5. E2训练：一次受控的小任务能力检查

| 项目 | 固定值 |
|---|---|
| 模型身份 | 3个fresh原dense D，seed92811–92813，不继承J/I |
| 结构 | 1,976,706参数；d128、4头、7块、MLP×4、RoPE base10000 |
| 精度与设备 | CPU FP32；无AMP/TF32；dropout0 |
| 更新数 | 每seed2048，总6144 |
| 每步batch | 48条：K1/K2/K4各16，从相应训练分区有放回取样 |
| 损失 | 隐藏query的精确概率软交叉熵 |
| 时间输入 | 小系统按t=1−K/16设置 |
| 优化器 | AdamW(.9,.95)、wd.05、clip1；EMA衰减.999 |
| 学习率 | 128步warmup到3e−4，余弦降到3e−5 |
| 主权重 | 预先固定的2048步final raw；EMA只作次要评价 |

若真值为q、模型预测为p，软CE为−q log p−(1−q)log(1−p)。减去真值熵H(q)，就是Bernoulli KL。它与在同一输入下反复抽硬标签的期望损失有关，但本轮直接用精确q，目标噪声更小。

训练只使用训练分区，不看留出预测调整步数；所有final含恢复字段，CPU恢复验证通过。raw优于EMA是结果，不是允许事后换主权重的理由。

## 6. 能力门：为什么同时看平均和最坏情况

每seed的K1留出、K2留出、K4拟合都必须满足：

- 最大模式KL≤.01；
- 最大概率误差≤.05。

3个seed×3个任务全部满足，才说这套固定小任务通过。.01和.05是事前诊断容差，不是普适物理常数。

平均误差低只能说明大量条件平均上较准；若少数模式严重失真，最大误差会揭示它。把“平均KL很小”改成“每种条件都可靠”是不成立的。

## 8. E4结果：答案没变，扩容后却失准

K4的四个单位最近邻完全保留，将任务嵌入8×8，其余新位置为有效MASK。由于完整最近邻已知，查询的真实条件概率仍由同一局部公式给出。

分别设置：

- 固定clock：仍用原t=1−4/16=.75。
- 自然clock：改用t=1−4/64=.9375。

| seed | 4×4 K4最大概率误差 | 8×8固定clock | 8×8自然clock |
|---|---:|---:|---:|
| 92811 | .001420 | .207911 | .202664 |
| 92812 | .001694 | .176169 | .171322 |
| 92813 | .001004 | .196410 | .178821 |

六个扩容评价都远高于.05。固定clock也失败，说明不能把退化全部归给时间输入随尺寸改变；自然clock结果同样失败，但这轮没有训练两个clock策略来比较哪种更优。

增加invalid PAD的严格控制通过；增加有效MASK则会改变dense网络的计算。二者不能混用。不变性检查允许的是数值容差内的指定等价变换，不能要求所有扩大物理容器操作天然保持输出不变。

这轮的关键进展是明确了：**小任务可学会，不等于已学能力能承受容器变化。** 失效原因仍可能涉及聚合、表示和训练分布，不是已唯一定位某一个内部机制。

## 9. E3复核与工程审计告诉了我们什么

旧J复核读取36预测、3个bank和12旧归档，不重训、不重新挑数据。复核标签差为0，没有发现用错oracle标签来解释J失败。

同时保留一项元数据更正：旧“all_64_backgrounds_independent”措辞过强，K4局部输入可以在不同背景记录中重复，不能当成64份独立物理信息。这个更正不重写J历史统计。

E1/E2还检查了平移、联合token/坐标重排、PAD和重复前向。严格控制容差为2×10⁻⁵；全局自旋翻转则不是模型硬编码保证，作为学习行为描述，不能把它与程序等价性混成一种门。

最终结论必须分开：

- 程序与来源审计通过，说明保存和执行可信；
- 专门小任务拟合通过，说明这一配方能学；
- 旧J混合配方仍未整体通过，说明不能用专门拟合成绩替代旧任务成绩；
- 扩容失败仍是有效科学结果，不被前两个“通过”掩盖。

## 10. 为什么这篇对N/W非常重要

Basic把大而模糊的失败转成一个可检验的问题：能否通过训练尺寸覆盖，让**真值不变的局部任务**在大容器中保持准确？

后续N/W进一步：

1. 保留原dense，避免再次混入结构变化。
2. 固定clock，控制时间输入的干扰。
3. 将窄尺寸与宽尺寸训练配对比较。
4. 用G8代替单纯可计数K4作为主任务。
5. 同时保留平均改善门与绝对最坏误差门。

这就是Basic的主线价值：它不是大型最终成果，却为更有解释力的核心实验建立了真值、能力门和问题定义。

## 11. 汇报前自测

- **O的结构反例能推广到所有attention吗？** 不能，依赖本实现的K/V限制和位置注入方式。
- **D随机初始化对距离有响应就算学会了吗？** 不算，只说明存在必要表达通路。
- **K4为什么不是充分几何任务？** 四邻全可见时概率只依赖符号和，可用计数完成。
- **为什么K4能扩物理域而K1/K2不能直接照搬？** K4的完整邻域屏蔽外部影响；K1/K2目标仍涉及外部边缘化。
- **raw通过而EMA失败是否构成挑模型？** 主raw已事前固定，EMA如实作为次要结果报告。
- **9/9通过是否等于大系统生成成功？** 不是；只是3seed×3个固定局部能力门，且8×8扩容另行失败。
- **为什么这轮没有漂亮生成图？** 没有执行生成，表格就是正式核心证据，不能用预检图冒充结果。

复述时按“J的疑问—结构检查—精确表—专门训练通过—扩容失败—引出N/W”讲，比逐条报超参数更容易理解。
