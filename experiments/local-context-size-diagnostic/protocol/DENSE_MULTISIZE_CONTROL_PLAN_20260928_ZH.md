# Dense多尺寸配对诊断：冻结方案

实验：`dense_multisize_control_20260928`。用户在上一份“先定位，再做dense单/多尺寸小对照”的建议后明确回复“请你继续”，授权本轮实现与执行。不是J或上一轮的重启、续训、预算延期；不训练O、不改网络结构、不做新MC/生成/长程大实验。

已知起点：上一轮三个D的final raw均通过4×4核心门，但8×8四邻居扩展失败。O的单点/同号几何退化不是本轮要通过训练修复的问题。老师要求dense多尺寸与真实距离变化分开验证；本轮只验证前者的一项局部必要能力。结构与距离训练的更广泛有效性均保持未验证。

## D1：只读现有权重的因素分离

- 复用上一轮92811–92813三个final raw，逐一核验文件SHA和身份，不修改或继续训练。
- query固定在(0,0)，四个观测在单位上下左右，遍历16种符号模式；真值是sigmoid(2βΣ邻居自旋)。所有外围点仅MASK，不含新观测。
- 交叉网格：有效token数N=16/32/64；仅外围MASK坐标倍率r=1/2；t=0.75/0.9375。基底坐标是[-3,4]²单位格点，固定query和四邻居；N16/32从包含四个最外角点的嵌套集合取点，N64为全格。两种固定几何选择顺序（先近后远/先远后近）。所有坐标唯一；r只移动外围MASK，四邻居距离绝不缩放。
- N64两个选择顺序最终是同一集合，不作两个独立重复；效应只以同seed/同布局/同模式的配对差描述。它不是新的独立物理场或MC样本。
- 同N与clock比较坐标效应；同外围范围与clock比较N效应；同输入比较clock效应，并保存交互网格。因改变的是输入表示，不能把每个差异唯一归因softmax分母。
- PAD阴性对照：同N16输入补无效PAD至64，必须≤2e-5概率差。此阶段不构建或评价12×12新主终点，不用D1结果选择训练组/超参数。

## 两个训练臂与配对

- A4：全部任务使用4×4容器。
- B46：K1/K2仍是同一个4×4精确任务；仅K4四邻居微批在奇数步用6×6、偶数步用4×4，各1024步。四邻居及query一起居中嵌入，外围全MASK，K4始终固定t=0.75。
- 注意：这是“同一局部条件问题的多容器训练”，不宣称所有任务或真实大系统分布已经多尺寸化。K1/K2扩物理域后真值会变，所以不搬用它们的4×4标签。
- 三个新种子92821/92822/92823，六个从零模型，各2048更新，总12288。每对A/B初始化逐位一致，原D架构1,976,706参数（宽128、4头、7块、dropout0、RoPE10000），没有预训练权重选择。
- 使用上一轮已核验的1,864行精确bank与同一整D4轨道划分。训练仅1296行，绝不使用568行几何留出。每步K1/K2/K4各16条有放回采样，每对共享完整物理样本、符号、query、target和clock。两臂唯一有意差异是B的奇数步K4容器。
- 每臂每步均分为32条K1/K2微批与16条K4微批，两次前向后将损失按32/48、16/48加权，一次反向/优化器更新。这样避免把PAD计算的额外开销误作科学变量；A也采用相同微批方式。
- AdamW(0.9,0.95)、weight decay0.05、clip1、EMA0.999；128步warmup到3e-4，余弦降至3e-5；CPU FP32、2计算线程、1 interop线程。
- 每256步交错A/B。所有六个final锁定并记录SHA前，不做最终能力评价；不早停到显著、不挑checkpoint、不加步、不选seed。固定final raw为主，EMA仅次要。
- 总更新和监督样本匹配，不宣称总token/FLOP匹配；B计算成本另行实测报告。

## 测试和判定（训练前固定）

- 4×4 K1/K2训练/原几何留出、K4拟合；6×6 K4是新增训练尺寸能力；8×8 K4是已知失效的开发复现点；12×12 K4是本轮未用于训练/调参的新尺寸，六final冻结后一次性评价。
- 6/8/12各64行（原四个query×全部16模式）。以四邻居解析公式逐输入核对真值；对称位置和模式不是独立训练seed。全部query隐藏、四观测完整、外围MASK仍attended。
- 固定t=0.75为主；自然t=1−4/N逐尺寸另报（6×6也未训练自然t）。主次不能互换。12×12不是整个大系统联合生成的验证。
- 所有保存概率计算精确Bernoulli CE/KL、期望Brier/超额Brier、平均/最大概率误差，逐seed及全模式保留。无MC参考误差；三seed均值MCSE用seed SD/√3，配对差用配对seed SD/√3。不构造虚假的模式级独立CI；三seed不够确认总体成功率。
- 能力门：每cell最大KL≤0.01且最大概率误差≤0.05。B的12×12固定clock须三seed全部通过；保留门是三seed的K1留出/K2留出/K4_4全部通过，并要求B的训练尺寸K4_6通过。
- 比较效应另列：P1是每seed的12×12固定clock平均KL(B−A)，报告全部三差值、均值、SD、MCSE。实质改善诊断门为每seed差≤−0.005。它和绝对能力门分开报告：仅误差下降但仍不合格不称修复；两臂都合格而差未达门不能归功多尺寸。该门是本次事前诊断容差，不是总体显著性检验。
- 对0.5及四邻居解析计数oracle基线同时报告；K4可由计数得到，因此成功只支持局部能力保留，不能代替K1/K2真实几何与长程验证。

## 预算、复现与停止

- 从本轮prepare开始记录唯一7200秒绝对预算，包含只读模型诊断、单测、测速、训练、评价、审计与打包。方案/代码编写发生在计时前。与已闭环J/上一轮预算无关，不能延长、重置或复用旧锁。
- 测速使用丢弃模型，分别测相同32+16微批、K4容器4及6：各8 warmup+3×12步。保守预测用各类型最慢组×1.5，按A全4及B半4半6的固定更新数加权，再留900秒作评价/审计/备份。只根据成本决定是否能启动，不根据loss改变设计。
- 若预测放不进剩余预算，停止并报告，不临时减少步数/种子。运行中每更新及每预测批检查deadline；硬失败保存failure及最新可恢复checkpoint，不自动重试。能力失败正常报告。
- 分层SeedSequence根2026092803，数据随机流不含arm，初始化流按seed共享；逐步physical与actual输入hash、loss、梯度、lr和CPU用时记录。严格冻结新代码/配置/方案及读入依赖与旧权重/数据SHA。
- CPU同环境下一步raw/EMA/AdamW/RNG恢复一致性测试；数据形状、隐藏query、解析真值、配对与容器不改邻居的单测；最终全步日志与输入hash重建，原数据及旧源只读。
- 保存全部逐行数组、六可恢复final、raw/EMA、协议、日志、报告和整包逐成员SHA回执。可变last仅用于中断保存，final不可排除；备份同D盘，不宣称异盘备份。保留C≥2GiB，不安装依赖、不登录远端、不改GPU资源、不删除旧数据。
- 当前交付以完整数值表/逐行数组为准，无生成图像任务；不为小诊断额外做论文图。若以后作图，必须从这些保存数组重建。

## 解释和后续边界

B训练尺寸不合格 → 固定配方仍未学会，不直接推论架构不可表达。B训练尺寸合格而12失败 → 本固定多容器训练不足以形成所测尺寸稳健性。B新尺寸与保留均合格且配对收益达门 → 本诊断支持继续回到原混合训练做能力确认，不自动证明老师完整idea。所有情况均不自动启动下一轮。
