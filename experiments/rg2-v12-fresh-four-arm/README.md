# 临界 Ising 模型的重整化训练与跨尺度生成

**ISM RG-2 v1.2 整合研究报告 · 2026-11-25**

本研究比较 Fine replay（F）、纯 RoPE 坐标增强（P）、中心抽点（D）和多数投票（M）：真实粗变量作为辅助任务，能否在可比训练预算下改善大尺寸细场生成，同时保留局部物理？

**主要阅读入口：[完整中文研究报告 REPORT_ZH.md](REPORT_ZH.md)。** 报告共12章及4个附录，自包含地说明历史实验、四臂输入、网络与训练、生成过程、完整物理曲线、联合分布机制和后续研究。全部数值来自冻结结果，没有为本次写作新增训练或生成样本。

- [修订与核验记录](integrated/REVISION_NOTES.md)：固定科学版本、修正内容、来源与复算结果。

真实MC中，抽点与多数投票约8.25%的块分歧伴随明显不同的关联振幅和磁化分布。两个Fresh开发seed在256步下，M的长程误差均小于F/D，但仍高于P，并伴随相对F的局部能量代价；64步的M−F/D方向随seed改变。当前证据没有证明M整体优于纯坐标增强，也不构成对其他重整化生成策略的否定。
