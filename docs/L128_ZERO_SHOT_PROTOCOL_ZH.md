# L=64 → L=128 零样本尺度外推实验协议

## 1. 科学问题

本实验检验：仅使用临界温度二维 Ising 模型的 `64×64` 样本训练的离散扩散模型，在冻结全部参数、不使用任何 `128×128` 样本微调的条件下，能否直接在 `128×128` 网格上生成正确的临界系综。

这不是普通的同分布测试。模型在训练时只看到 `L=64`，而推理时格点数从 4096 增加到 16384。真正关键的证据不是单张图片是否“像”，而是模型是否同时重现：

1. 局域相互作用统计，如能量密度；
2. 全局涨落统计，如磁化分布、Binder cumulant；
3. 长程关联，如两点关联函数 `G(r)` 和低波数结构因子 `S(k)`；
4. 从 `L=64` 到 `L=128` 的有限尺寸 scaling 趋势。

## 2. 固定条件

- 训练尺度：`L=64`。
- 推理尺度：`L=128`。
- 权重：`artifacts/pilot_l64/best.pt`。
- 权重状态：冻结，不训练、不微调。
- 离散扩散采样器：ancestral。
- 反向扩散步数：128。
- logit temperature：1.0。
- 模型样本：3 个独立 sampling seed，每个 1536 张，共 4608 张。
- seeds：1234、2345、3456。
- 推理 batch size：32。
- 计算设备：单张 RTX 5090。

使用多个 seed 的目的不是重复展示图片，而是检查生成系综的结论是否依赖一次随机采样。每个 seed 产生不同的初始噪声和反向采样随机数；三组统计量应彼此接近。

## 3. Monte Carlo 参考系综

L=128 参考数据由独立 Wolff cluster Monte Carlo 生成，不从 L=256 裁剪，也不复用训练数据：

- 样本数：10000；
- 独立链：8；
- burn-in：500 sweeps；
- 相邻保存样本间隔：5 sweeps；
- seed：20260807；
- 临界逆温度：二维正方格 Ising 模型的理论临界点；
- 周期边界条件。

生成后的收敛诊断为：

- energy split-Rhat：0.999886；
- `|m|` split-Rhat：1.000264；
- 最小单链 ESS：624.92。

这些量支持参考系综已达到平衡并具有足够的有效独立样本。MC 的作用是给模型评分，因此必须与模型输出独立。

## 4. 为什么把 r=32 作为分界

在周期边界的 `L=64` 网格上，沿单一坐标轴能区分的最大最短距离是 `L/2=32`。模型虽然采用可计算任意尺寸相对距离的函数式位置偏置，但训练数据没有直接约束 `r>32` 的统计。

因此将相关函数误差分成两段：

- `r=1..32`：训练尺度内可见的距离范围；
- `r=33..64`：L=128 才出现的长距离范围，是尺度外推的核心检验区间。

这里的“未见”指训练系综没有包含这些绝对距离，并不意味着网络完全没有归纳偏置。卷积、轴向注意力、周期距离位置偏置都可能帮助外推，但是否成功必须由独立统计检验决定。

## 5. 主要指标

### 5.1 能量密度

最近邻 Ising 能量密度：

\[
e=-\frac{1}{L^2}\sum_{i,j}\left(s_{i,j}s_{i+1,j}+s_{i,j}s_{i,j+1}\right).
\]

它主要检查局域红蓝边界数量是否正确。能量准确不等于长程结构准确，因此不能单独证明模型学到临界性。

### 5.2 磁化

\[
m=\frac{1}{L^2}\sum_i s_i.
\]

记录 `m`、`|m|` 和正负模式比例。有限尺寸临界系综中的单张图片不要求红蓝各半；由于长程涨落，`m` 可以显著偏离 0。要求的是整个系综满足自旋翻转对称，而不是每张图片都满足 50:50。

### 5.3 Binder cumulant

\[
U_4=1-\frac{\langle m^4\rangle}{3\langle m^2\rangle^2}.
\]

它对磁化分布的形状敏感，并且是临界有限尺寸分析中常用的无量纲量。仅匹配平均磁化不足以保证 Binder cumulant 正确。

### 5.4 二阶矩关联长度

由零动量和最小非零动量处的结构因子估计 `xi_2`，报告无量纲比值 `xi_2/L`。若模型在 L=128 产生过强的全局大团簇，通常会表现为 `xi/L` 偏大。

### 5.5 两点关联函数

\[
G(r)=\langle s(x)s(x+r)\rangle.
\]

对周期平移和相同半径方向平均。临界二维 Ising 模型在无限体积极限具有 `G(r) ~ r^{-1/4}`；有限周期格点上会有明显有限尺寸修正，因此报告模型与同尺寸 MC 的直接比值比强行拟合理论直线更可靠。

分别计算：

- `NRMSE(r=1..32)`；
- `NRMSE(r=33..64)`；
- `G_model/G_MC` 在 r=8、16、32、48、64 的值；
- r=4..32 和 r=16..48 两个区间的有效幂律指数及拟合优度。

### 5.6 结构因子

\[
S(k)=\frac{1}{L^2}\langle |\tilde s(k)|^2\rangle.
\]

低 `k` 对长程和大尺度团簇最敏感。模型即使能量正确，只要低 `k` 明显高于 MC，就说明全局结构过强。

## 6. 预先固定的 pilot 判据

在查看正式 4608 张模型样本之前，固定以下宽松的 pilot 判据：

- `|<m>| < 0.10` 且正磁化比例在 `[0.35, 0.65]`；
- 能量绝对误差 `< 0.03`；
- `<|m|>` 绝对误差 `< 0.06`；
- Binder `U4` 绝对误差 `< 0.05`；
- `xi/L` 绝对误差 `< 0.12`；
- `G(r)` 在 r=1..32 的 NRMSE `< 0.08`；
- `G(r)` 在 r=33..64 的 NRMSE `< 0.12`。

这些是判断“是否值得继续扩展”的 pilot 阈值，不是严格的理论等价证明。报告必须逐项列出 PASS/FAIL，不能只给总体印象。

## 7. 不确定性和稳定性

- MC 参考采用以独立链为单位的 bootstrap，避免把同一链内相关样本错误地当成完全独立样本。
- 模型采用 seed 分层 bootstrap：先重采样 seed，再在 seed 内重采样图片。
- 主要标量报告 95% bootstrap 区间。
- 单独绘制三个 seed 的能量、`|m|`、Binder `U4` 和 `xi/L`，排查偶然模式偏置。

## 8. 运行流程

### 8.1 正式采样

```bash
bash scripts/run_l128_zero_shot_formal.sh 1234 2345 3456
```

脚本为每个 seed 建立独立目录，并在发现完整 `samples.npz` 与 `metrics.json` 时跳过已完成任务，支持中断后的安全续跑。

### 8.2 聚合分析

```bash
bash scripts/run_l128_analysis.sh
```

该脚本检查三个 seed 是否完整，然后运行 `analyze_l128_zero_shot.py`，计算 1000 次 bootstrap 并生成图表、CSV 和中文结果报告。

## 10. 结论边界与后续实验

即使 L=128 全部通过，也只能说明当前网络在两倍线性尺寸上保持了所测临界统计，不能用两个尺寸点精确估计普适临界指数。更强的 scaling 结论需要至少加入 L=96、192、256，并对

\[
\langle|m|\rangle = A L^{-\beta/\nu}(1+B L^{-\omega}+\cdots)
\]

等形式做有限尺寸修正拟合。

若 L=128 的局域能量通过、但 `xi/L`、低 `k` 结构因子或 `r>32` 的 `G(r)` 失败，则应判断为“学会局部临界纹理，但未正确外推全局尺度”。下一步应优先改进多尺度训练目标、尺度条件化或长程一致性损失，而不是单纯增加采样步数。
