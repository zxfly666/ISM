## 研究问题与三臂

在同样的细尺度学习上，加入真实粗粒化数据，是否比等计算量的细尺度重放更能改善细尺度条件预测，同时学会粗尺度目标？这不是逆 RG，也不检验完整生成分布正确性。

固定使用最小的三个旧 I-F 谱系 92601–92603；选择与其结果无关。三臂每个谱系初始化完全相同：旧 global12000 的 EMA 权重、新增零初始化的二级尺度嵌入。AdamW 与 RNG 重新初始化；明确不是沿用旧 AdamW 的完整续训。

- fine_only：2048 次共同细尺度更新。
- fine_plus_rg：2048 次共同细尺度更新，加 2048 次真实 3×3 多数投票粗尺度更新。
- fine_replay：2048 次共同细尺度更新，加 2048 次额外细尺度更新。

后两臂参数数目、更新次数、输入 token 数、共同细尺度输入、辅助输入的父样本/原点/自旋翻转/坐标对称性/时间/掩码随机流均配对。辅助粗尺度取 3W×3W 场并映射为 W×W；重放取同一场中央 W×W。物理视野差异是该 RG 数据干预的组成部分，不能声称已将所有尺度效应分离。每步 18432 token，16/24/32/48 的固定均衡循环，共 30720 更新。每 256 个共同周期轮换九个模型，固定中点和终点保存，禁止按效果早停或挑 checkpoint。

所有模型结构相同：原坐标模型加 2×128 零初始化尺度嵌入，加入时间表示。细尺度坐标单位为 1；粗尺度块中心为 3i+1，单位仍是细格点。粗尺度标签显式为 1，不把粗尺度数据冒充另一个温度。训练采用既有 BF16 autocast、FP32 参数/损失/优化器，TF32 关闭、严格确定性；所有报告预测用 FP32。学习率按共同周期定义，辅助更新与其紧邻共同更新使用相同学习率。

## 数据与真值

训练只使用旧训练父样本；学习曲线只使用旧验证父样本中固定 64 个。测试复用已完成评价的新 MC 参考中的 256 个父样本，固定每链 16 个，共 16 链。三个来源整场自旋摘要必须互不重合。空间 patch 不是独立的实验重复，三个模型谱系才是模型层的独立单位。MC 已在先前研究中查看过，因此本轮不是全新盲测，也不是确认性重复。

细尺度 W48/W96、M=1/8/32 的棋盘内部查询使用原细格点 Ising 精确局部条件概率，报告每个父样本的 KL/CE。多数投票后的目标只报告对真实留出粗尺度标签的经验 CE；绝不套用原细格点的最近邻 oracle。另报告粗尺度 level=0 的固定消融，避免只用未训练的尺度标签评价基线而掩盖解释限制。细尺度留存以 W48、t=.1/.5/.9 的经验 CE 报告。

## 预定主汇总及统计

主汇总为 W96 三个 M 的平均精确局部 KL，fine_plus_rg 减 fine_replay。次汇总为粗尺度 W32 三个 t 的平均 CE，以及细尺度留存。全部三谱系、三臂、所有固定测试格点和失败公开；不得改选有利格点。

报告三个谱系的配对差、95% 配对 t 区间（df=2），以及固定 2000 次 seed→MC chain→链内连续父样本循环块（块长4）的配对层级 bootstrap。bootstrap 同一次抽样中所有模型共用参考样本；这里不是渐近覆盖率验证，三谱系精度不足，bootstrap 也不能创造额外谱系。任何方向信号只作探索性结果。细尺度 CE 增量大于 .002 标为留存警告，不停训、不加步。保存原始父样本级预测与标签，可 CPU 重算。中点学习只作欠收敛提示，不选模型。
